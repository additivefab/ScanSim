# 逐时刻记录与接口说明

## 三种时间粒度

默认模拟内部细步为 6.25 ns（20 MHz ADC 的 8 倍细分）；ADC 采样间隔 50 ns；行事件周期 1 ms。光路飞行时间和 PMT 渡越时间通过延迟模型体现，不对可见光载波逐周期计算。内部细步逐次更新光功率、光子统计与模拟状态，但交付追踪 CSV 每个 ADC 时刻保存一次，不包含所有细步。修改代码可增加细步导出，通常先缩小到单行以免数据暴涨。

默认记录前两行的整个采集保护窗口，共每行 832 个 ADC 采样记录。整帧行事件另见 frame_events.csv。空白期采用事件/稳态近似跳过，不是把未计算的细步伪装成完整记录。

## first_lines_trace.csv 字段

| 字段 | 单位/含义 |
|---|---|
| line | 行编号，从 0 起 |
| adc_cycle | 当前行内 ADC 时钟序号 |
| sample_time_s | 当前 ADC 样本的物理时刻（全局秒）；采用每周期中点的坐标约定 |
| bus_settle_time_s | 当前数字总线输出稳定的名义时刻：sample_time_s+tPD；不是 ADC 采样时刻 |
| source_sample_time_s | 当前总线码所属的原始采样时刻，当前时刻减流水线延迟 |
| x_sample_equiv_px | 扣除标称模拟群延迟后的等效横坐标；不是此刻光斑的未经补偿真实位置 |
| y_sample_equiv_px | 对应等效纵坐标，含连续送片位置 |
| p_detector_w | 当前记录时刻的模型光功率；不要误认为和所有后级电压属于同一零延迟位置 |
| pmt_anode_a | 含噪声及 PMT 响应后的阳极电流 |
| v_log_v | 对数前端响应电压 |
| v_adc_diff_v | 抗混叠等效滤波后的 ADC 差分输入；非已确认的模块 SMA 对地电压 |
| adc_sample_code | 当前模拟采样对应的量化码 |
| adc_bus_code | 经 12 个示例周期后当前出现在功能总线的码 |
| sample_valid | 当前样本是否归入有效采集区 |
| bus_valid | 与数据一起延迟后的有效标签 |
| bus_pixel_col | 延迟后样本对应的目标像素列；无效时 -1 |
| adc_saturated | 当前量化输入是否触及 ADC 范围 |

首次流水线未填满的总线码应忽略；必须检查 bus_valid，不可把零码自动当有效黑像素。该记录只建模整数 CMOS 流水线；LVDS 半周期差异、输入建立保持时间、DCO 眼图、时钟域跨越需要独立设计。

## 图像/原码格式

`adc_active_u16le.raw` 默认为 128×512、单通道、行优先、uint16 小端，计 131,072 字节；512=256 输出像素×2 样本/像素。准确尺寸读取同目录 raw_format.json，不写死。

它只保存有效标签窗口的 ADC 码，不是光学密度；实际重建使用保护窗口及分数延迟插值，边界重算可能还需要保护样本。完整可重复生成应使用 config_used.json、相同代码/依赖和种子。前两行的保护样本已在 CSV，其余行的完整保护窗口并未单独导出。

`simulation_arrays.npz` 保存 truth_density、blurred_transmission、density、transmission、invalid、optical_reference_density、white_current、opaque_current。`density_float32.tiff` 保存浮点光学密度；无效点必须配合 invalid_mask.png 使用。PNG 是显示预览而非额外精度。

## Python 与 RTL 的连接边界

`results/default/rtl_vectors.hex` 是前 256 个有效模拟 ADC 码；交付时复制到 `rtl/vectors.hex`。RTL 测试平台读取这些码，检查 12 周期标签和有限 FIFO。它不是 Python 与 HDL 的实时协同仿真，也不表示实际 AD9268 引脚接收或 DMA 已实现。重新生成参数后，手动复制新的向量再运行外部 RTL 仿真。

## 实测数据导入的下一步

保留示波器原文件；在 measurement_templates 中统一时间、通道、电流/电压/密度单位。先独立拟合静态对数/标定 LUT，再拟合分光强动态带宽，最后识别每镜面 x(t) 与编码器 y(t)。模板目前是空表，尚未包含特定仪器驱动或自动拟合器。
