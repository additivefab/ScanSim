## 01 现有资料能确认什么

用户调研记录第 1 页标注了激光源、所谓“棱镜”和 f-场镜；第 2 页标注 PMT、高压模块、对数放大器及“有效范围”示波器波形；第 3 页可读 ADC_AD9268_V4.2、双通道、125 MSPS、16 bit 等模块丝印。[U1]

用户原始调研照片：这是器件位置证据，不是已验证的完整光线追迹图。[U1，第1页]

照片中的旋转件适合首先按多面反射转镜建模；原记录“棱镜”的称呼不能证明它是透射棱镜。扫描镜组按等效平场/f-theta 映射起步，实际每片镜子的顺序、曲率、间距和反射/折射方式仍需现场确认。

接收侧只能确认存在 PMT 与集光区域，不能仅凭照片断言是积分球、某种导光棒或某个确定结构。对数板的具体芯片也未被确认，资料中的 AD8304 只作为原理参考。[U1；R3]

独立开发板正面照片可读 Smart ZYNQ SP2 V1.3B。所给原理图确认 Zynq-7020、512 MB DDR、PL 50 MHz 时钟、J5/J6 与 RTL8211E 等资源；它不是整台扫描仪或 ADC 模块的完整原理图。[U2，第1、2、5、10、12页]

## 02 从激光到数字图像的完整链路

主工作假设：已显影底片的透射式、单波长、单探测通道灰度扫描。激光负责逐点照明，不是给底片写入新的影像；像素表示该位置对该波长的透射信息。若目标是彩色负片，必须增加多光谱/RGB 采集和色彩标定，单一波长不能恢复任意彩色图像。

| 环节 | 光或电信号发生什么 | 证据与建模方式 |
|---|---|---|
| 激光源/驱动 | 电流驱动形成光功率 P0(t)，可连续发光或受控消隐 | 有光源照片；波长、功率、开关策略未知。 |
| 准直/整形/折转 | 限制光束发散，设定入射束径、方向和偏振 | 常见功能，实际元件存在与顺序待核对。 |
| 旋转多面镜 | 镜面转动使反射光束横向扫过一个角度区间 | 照片与扫描用途支持，面数/转速未实测。 |
| 扫描聚焦镜组 | 把角度映射为片面位置，控制焦斑、像差、场曲 | 等效 f-theta + PSF；不假造光学处方。 |
| 底片 | 局部透射率调制光通量；吸收和散射同时存在 | 透射式模型假设，D=-log10(T)。 |
| 集光/遮光/滤光 | 把透过底片的光收集到 PMT，并抑制杂散光 | 接收结构待确认，用位置相关效率与杂散项表示。 |
| PMT | 光阴极发射电子，倍增极放大，阳极给出电流 | 光电转换发生在这里；高压是供电支路。 |
| 模拟前端 | 电流转为对数电压，可能再增益/偏置/滤波/差分驱动 | 一级对数板有标注；其余细节待原理图确认。 |
| ADC | 采样保持、量化、流水线输出数字码 | 丝印指向 AD9268；实际输入网络和输出模式未知。 |
| FPGA/DDR/主机 | 给样本加坐标与有效标签，缓存、传输、标定、重建 | 开发板资源已知，应用逻辑需自行实现与验证。 |

控制支路与主链路同样重要：激光使能、转镜转速/锁定、SOS 行同步、送片电机、编码器、PMT 高压稳定、ADC 配置、FIFO 溢出、DMA 完成和帧校验。它们共同决定“这个数属于底片哪里”。

PMT 不是一整排同时读出的相机像素。位置来自扫描时刻与机械位置；PMT 的时间信号被逐点赋予二维坐标，最终才构成图像。[R2；U1]

## 03 光束怎样扫描：角度、坐标和送片

设多面镜有 M 个面、转速 r rpm，每个有效面产生一行，则行频 f_line=M·r/60，行周期 T_line=1/f_line。这个关系要求每个镜面都参与一次有效扫描；实机若跳面或有双束光，需修改事件模型。

```text
theta_m(t) = theta_0 + omega_m*t,    omega_m = 2*pi*r/60
phi(t) ≈ 2*theta_m(t) + phi_0
x(t) ≈ f*phi(t) + distortion(phi, facet)
v_x ≈ 2*f*omega_m
pixel_rate = v_x / pitch_x
f_ADC = samples_per_pixel * pixel_rate
```

反射角变化约为镜面机械角变化的两倍；f-theta 镜组使位置近似与光学扫描角成正比。普通透镜的理想几何映射近似 f·tan(phi)，不能不加区别地使用同一模型。实际镜组应以 x(t,facet) 测量表或光线追迹结果替换上述近似。[R4]

慢轴若连续送片：y(t)=y0+v_y·t，行间距 pitch_y=v_y/f_line。一次横扫期间底片仍在运动，所以光束在材料坐标中并非严格水平。在完整预算场景中，700 µs 有效扫描期间底片移动 35 µm，即 0.7 个 50 µm 像素，需要几何重采样。

若实机采用“扫完一行再步进”，则必须模拟电机加减速、定位误差和稳定时间，而不是默认空白期内能瞬间到位。本包默认连续送片；continuous_feed=false 仅代表理想静止行，不是已仿真的步进电机。

每行还包括非成像区：镜面进入、片外边缘、参考区、片面有效区、退出与下一镜面的间隙。SOS 检测光路可能来自专用光电探头、镜面控制器或其他信号，现有资料不足以确认。不要把示波器上的周期波形直接当作已证实的 SOS。

时序误差会变成位置误差：delta_x=v_x·delta_t。以示例 v_x=500 m/s 计，10 ns 是 5 µm，即 0.1 像素。单纯在 50 MHz 域用两级触发器同步异步 SOS，可以降低亚稳态传播风险，但不能消除时刻量化误差；必须评估采样相位、恒定延迟与抖动。

## 04 底片与光斑：不能直接把密度当亮度

```text
D(x,y,lambda) = -log10(T(x,y,lambda))
T = 10^(-D)
T_eff(x_s,y_s) = integral[T(x,y)*h_PSF(x-x_s,y-y_s) dx dy]
P_det(t) = P0(t)*eta_pre*eta_collect(x_s)*attenuation*T_eff + P_stray
```

D 是光学密度；D=0、1、2、3、4 对应透射率 1、0.1、0.01、0.001、0.0001。仿真输入应是透射率图或可转换为透射率的密度图。普通手机照片/JPEG 的灰度通常经过曝光、伽马和压缩，不能直接作为定量密度真值。

有限光斑照亮的是一个小区域，而不是数学上的点。必须先将密度转为透射率，再与归一化 PSF 卷积；“对密度图先模糊”会给出不同且通常不正确的物理结果。本包自动测试专门检查这一点。高斯 PSF 是起步近似，后续用实测刀口/狭缝结果或镜头模型替换。

激光是相干光源，本包没有模拟散斑、薄膜干涉和真实银盐颗粒的波动光学散射。它将这些效应留给实测 PSF/噪声统计或后续局部物理光学模型，不把“能追迹几条光线”等同于已完成真实图像形成。

杂散光不能只当成普通白噪声。若接收光中存在比例 epsilon 的稳定漏光，未校正的 T_meas≈T+epsilon，在深密度区会出现 apparent_D≈-log10(epsilon) 的读数平台。遮光参考可校正稳定偏置，但不能消除漏光产生的散粒噪声和随位置变化的不确定性。

采样间距与分辨率分开报告：50 µm 网格的奈奎斯特空间频率是 10 lp/mm，但这并不保证在 10 lp/mm 仍有足够对比度。光斑、运动、模拟带宽、像素平均和重采样共同决定 MTF。

高斯光斑可用 MTF_opt(nu)=exp[-2*pi²*sigma²*nu²] 作初步预算。扫描把空间频率 nu 转成时间频率 f_t=v_x·nu，所以必须把前端传递函数 H(f_t) 也纳入分辨率预算，而不能只看 ADC 采样率。

## 05 PMT：光子、电子、增益与高压

PMT 的光阴极将入射光转换为初级光电子，倍增极链再放大电子数，阳极输出电流。高压电源与分压链建立电场，不是光线经过的元件。量子效率、增益、暗电流、磁场、温度、平均/峰值电流线性度均依具体型号和工作点而变。[R2]

```text
E_photon = h*c/lambda
N_e = P_det*Delta_t*QE/E_photon
R_cathode = QE*e*lambda/(h*c)       [A/W]
I_anode_mean = G*R_cathode*P_det + I_dark
sigma_D ≈ 0.434*sqrt(F/N_e)       (shot-noise-only, high-count limit)
```

本包使用泊松光电子数，并用 Gamma 随机倍增近似过剩噪声因子 F。低光照时不能随意用“均值加高斯噪声”代替离散光子，否则可能产生负光子和错误的密度尾部。暗电流在示例中按等效初级暗事件建模，真实 PMT 的暗噪声成分需测量。

示例光子预算：635 nm、透明处 PMT 入射功率 200 nW、QE=0.2、每像素 100 ns，透明处约 1.28×10⁴ 个初级光电子；D=3.5 后仅约 4 个（不计杂散光）。即便 ADC 有 16 位，深密度区也不能凭空恢复缺失光子。

提高 PMT 增益只放大已存在的信号与噪声，不能把初级光子统计重新变好；过大的透明区阳极电流还可能进入非线性。设计可在仿真中比较延长驻留、降低扫描速度、合适光通量/增益组合、多次曝光和双量程，但每种方案都须同时满足探测器额定值与安全边界。

示例 G=1000、QE=0.2、暗阳极电流 50 pA、限幅 100 µA 都是教学假设，不是对现有 PMT 的建议设置。必须取得 PMT 型号、高压模块和分压链资料，再决定实际允许范围。

安全底线：真实调试应先完成封闭光路、激光联锁、正确波长的防护与高压绝缘。不得按本包示例直接设置高压，也不要把普通示波器接地夹连接到 PMT 高压节点。高压/光功率测量应由具备相应能力的人员按器件资料和现场规则执行。[R2]

## 06 模拟前端：对数压缩不等于理想瞬时计算

依据照片，将一级前端建模为电流输入的对数转换；可能还有二级增益、偏置、保护、抗混叠和 ADC 驱动。不要在不知道电路的情况下，默认一定先经过一个独立线性跨阻放大器，再进入某型号对数芯片。[U1，第2页]

```text
V_log = V_offset + S*log10(max(I_anode,I_floor)/I_ref)
V_ADC_diff(t) = H_AA { H_log { V_log(I_PMT(t)) } }
I_hat[n] = I_ref*10^((V_hat[n]-V_offset)/S)
```

若 I 与透射率成正比，则理想静态对数电压近似与密度呈线性关系，正负方向由电路极性决定。但这只是在已扣暗电流、无饱和、无杂散偏置和增益稳定等条件下成立。真实动态响应不能用一条直线完全替代。

对数放大器的带宽常随输入电流变化。作为原理例子，AD8304 官方资料说明低电流时带宽降低；这不能证明实际扫描仪用了 AD8304，也不能把其数字直接带入实际板卡。[R3]

本包提供两种可选模型：固定带宽；以及“电流越小，带宽越低”的可配置行为模型。后者的 knee、floor 和比例规律均为假设，用于暴露可能的高密度拖尾，必须由前端阶跃/小信号测量替换。

必须测至少三类响应：透明→深密度、深密度→透明、同一小信号阶跃在多个直流光强偏置下的响应。分别记录上升/下降、过冲、恢复、饱和和基线，而非只在明亮条件下量一个带宽。

ADC 模块若使用交流耦合电容或变压器，可能丢失底片密度所需的直流和低频成分。裸芯片支持差分采样，并不保证某个模块的 SMA 输入是直流耦合。必须核查模块输入网络；spice/ac_coupling_risk_ngspice.cir 是这一风险的教学示例。

本模型采用一阶 PMT 响应、一阶对数响应和两级缓冲 RC 等效滤波。它没有真实运放输入电容、环路稳定性、共模、压摆率、寄生、供电纹波和完整噪声谱，不可用于电路签核。

## 07 ADC：模拟采样时刻与数字输出时刻不同

AD9268 官方资料描述其为双路、16 位差分流水线 ADC，具有 CMOS/LVDS 输出选择。模块丝印支持以该芯片为核对方向，但仍须检查实物芯片等级、模块时钟和寄存器配置。[R1；U1，第3页]

| 项目 | 应如何解释 |
|---|---|
| 125 MSPS | 模块标称档位/最高能力线索，不是已经测得的实际运行采样率。 |
| 示例 20 MSPS | 符合资料中 DCS 开启时的转换速率下限；并非为了演示就随意降到 1 MSPS。 |
| CMOS 模式流水线 | 数据手册给出 12 个转换周期；20 MSPS 对应 600 ns。 |
| LVDS 模式 | A/B 数据时序存在 12/12.5 周期差别，不能照搬单一路 CMOS 标签逻辑。 |
| 差分输入范围 | 本包用 -1..+1 V 的差分量；不表示任一芯片引脚可相对地为负电压。 |
| 输出逻辑电平 | 裸片 CMOS 输出采用 1.8 V 体系；模块是否电平转换需要核实。 |
| 16 位 | 表示数字码宽，不是无噪声位数，也不是全链路密度精度。 |

```text
LSB = (V_max - V_min) / 2^B
code[n] = clip(floor((V[n]-V_min)/LSB), 0, 2^B-1)
V_hat[n] = V_min + (code[n]+0.5)*LSB
code_bus[n+L] = code_sample[n]
```

模拟采样过程是对当时输入的采样保持；数字码随后经过流水线才出现在输出总线。还要叠加输出传播、输入捕获和 FPGA 逻辑延迟。tPD 与 DCO 相位是电气时序问题，不应简单靠在软件里多加一个整数周期来掩盖。[R1，第9–11页]

所有位置和有效标签必须与 ADC 数据对齐：line_id、facet_id、sample_id、pixel_col、valid、行尾/帧尾，以及错误状态。只延迟数据、不延迟标签，会在每行两端产生丢样、错列或把下一行写进上一行。

本包只执行 ADC 的行为量化、噪声、饱和和整数 CMOS 流水线。未模拟采样开关电荷注入、INL/DNL 的真实测量曲线、LVDS 训练或 FPGA 端建立/保持时间。

## 08 每个时间步发生什么

不存在一个对整机都合适的“最小时间步”。系统应同时保存物理时间、ADC 样本编号、行号、镜面号、运动位置和输出流水线状态。以下数值只对应教学配置；t=0 是已假定完成预热、锁速和标定后的第 0 行 SOS。

| 时间/事件 | 发生的事情 |
|---|---|
| 启动前 | 保持激光安全状态；检查通信/联锁、回零、锁速、PMT稳定、暗/白/密度参考。各持续时间必须实测。 |
| t=0 | 假设 SOS 到达，登记行号0/镜面0，并开始当前行位置计时。 |
| 98 µs | 示例打开激光门，留出2 µs片外前导区域；真实机器可能一直发光。 |
| 100 µs | 光斑进入仿真的底片裁剪有效区，光通量开始携带该区域透射信息。 |
| 光传播/探测延迟 | 示例1 m光程约3.336 ns；再加假定20 ns PMT渡越及模拟动态响应。 |
| 每50 ns | 20 MSPS ADC 采一次模拟电压；每个输出像素使用2个ADC样本。 |
| 100.175 µs | 本例第一个有效采样标签所在采样中心；群延迟补偿约159.944 ns并量化到采样网格。 |
| 100.775 µs之后 | 上述样本在12周期后到达功能总线；传播延迟示例另记3.5 ns。不是光线此时才穿过底片。 |
| 125.6 µs | 裁剪光学有效区结束；必须继续接收模拟尾部和ADC流水线尾部。 |
| t=1 ms | 下一镜面行周期开始；底片已前进50 µm。 |
| 128个行周期后 | 完成教学128行；还必须确认总样本数、最后数据写入、错误标记和文件落盘。 |

同一时刻的系统是并行的：激光正照向位置 A，模拟输出可能仍混有前面位置 B 的响应，ADC 正采样该模拟量，总线上输出的是更早位置 C 的数字码，DMA 又在搬运更早的数据块。绝不能把它理解为“每个光子走完整条链后才发下一束”。

first_lines_trace.csv 逐 ADC 采样记录前两行采集窗口；frame_events.csv 记录整帧的行级事件；viewer/index.html 可拖动到每个 ADC 采样时刻。空白行区采用事件/稳态近似跳过，不虚构数亿条无变化记录。

## 09 怎样把一维波形恢复成完整二维数字底片

第一步是保留原始 ADC 码和采集元数据，而不是只输出一张经过自动拉伸的图片。每个样本需要唯一对应到采样时间与扫描位置，原始数据将用于重新标定和排查错误。

第二步是静态反演与参考校正。线性前端可用 T=(C-Cdark)/(Cwhite-Cdark)；但对数前端不能直接套用这条码值比值公式，必须先根据实际传递函数反算电流或功率，再扣暗参考并归一化。

```text
For logarithmic front-end:
  V_hat[n] -> I_hat[n] by inverse log / measured LUT
  T_hat[n] = (I_hat[n]-I_opaque[n]) / (I_white[n]-I_opaque[n])
  T_pixel = resample_and_average(T_hat[n])
  D_pixel = -log10(T_pixel)
```

本包先逐 ADC 样本反对数，再进行位置重采样及像素平均。直接平均对数电压/密度与先平均透射率后求密度不是同一物理量。模拟滤波位于对数变换前后也会改变结果，因此动态拖尾不能靠静态公式完全消除。

第三步是几何校正：用 SOS/镜面号建立 x(t,facet)，用编码器或运动模型建立 y(t)，补偿固定延迟，按实际非均匀坐标采样到规则网格。标称群延迟补偿只是小信号近似；需要更精确时，应测量动态模型并评估受噪声约束的反卷积。

第四步是形成行与帧：保证每行规定的有效样本数；写入行号、镜面号、方向；连续送片情况下做行内斜扫校正；核对缺行、重行、溢出、SOS超时、编码器停顿和帧尾。FIFO溢出后不能仅把后面的数据向前补齐而宣称图像完整。

| 输出文件 | 含义 |
|---|---|
| adc_active_u16le.raw + raw_format.json | 单通道、行优先、uint16小端；每行512个原始ADC样本，不是密度图。 |
| simulation_arrays.npz | 保存透射率、浮点密度、光学参考、校准参考和无效掩膜。 |
| density_float32.tiff | 定量密度行为仿真结果；需同时查看invalid_mask.png。 |
| density_preview.png | 仅为线性显示密度的8位预览，不代表额外精度。 |

单色底片的显示正负片可以通过显示映射切换，但这不改变定量透射率/密度数据。DICOM、工业检测报告格式及相应质量规范需另行实现和验证，本包不伪造这些合规成果。

## 10 仿真设计：分层、多速率、逐步替换

| 层级 | 输入与输出 | 建议时间/空间尺度 |
|---|---|---|
| 几何与光学 | 转角、元件/PSF、密度图 → 片面坐标/入射光功率 | 先用位置/角度查表；本包片面4倍超采样。 |
| 光电与模拟 | 光功率 → 光电子/PMT电流 → 对数/滤波电压 | 教学细步长6.25 ns，可用4/8/16/32倍ADC细分做收敛检查。 |
| ADC与RTL | 模拟电压 → 码值/延迟/valid/缓存 | 20 MSPS即50 ns；FPGA不同域须另作CDC。 |
| 运动/行同步 | 镜面、SOS、编码器 → 有效窗口与坐标 | 行级事件1 ms；运动连续解析，不强制每个光学细步驱动电机。 |
| 帧/文件/网络 | 行数据 → 缓存占用、图像和错误报告 | 块/行级事务；不把每个DDR引脚也塞进模拟光路模型。 |

推荐用“接口变量”连接模型：光学侧输出 x/y/有效透射率/接收功率；模拟侧输出电压波形及采样时刻；数字侧消费 ADC 码和测试标签。CSV/NPZ/HEX 是本包的交换格式，未来可以用 Python、Simulink 或供应商联合仿真接口替代。

不建议全机FDTD：可见光振荡周期为飞秒量级，而整帧扫描可能是秒量级；把两者放进统一时间网格既不必要，也不能弥补未知镜头处方。只有当局部衍射、干涉或器件微结构确实是问题时，才对局部系统采用物理光学/电磁求解。

当前模型的模拟低通采用分段线性输入的一阶精确递推，避免朴素“当前点零阶保持”造成半个细时间步的相位偏移。但它仍是离散近似，必须做收敛实验。

本包已执行收敛检查：无随机噪声、128×32测试图，8→16倍细分结果的密度差RMS约4.32×10⁻⁴，16→32倍约1.17×10⁻⁴。该结果只说明这组测试的数值离散趋稳，不说明光学/电路假设已经符合实机。完整结果在results/convergence.csv。

逐步升级：先跑理想图验证坐标与码值；再逐项加光斑、动态带宽、光子噪声、杂散、镜面误差；最后用实测数据替换参数和子模型。不要一次加上所有未知误差后靠调参“看起来像照片”。

## 13 FPGA实现：先仿真数据归属，再接真实ADC

建议硬件处理链：ADC源同步接收 → 测试码/位序验证 → 标签对齐 → 原始有效窗口 → 异步FIFO → 校正/抽取或原码打包 → AXI4-Stream → AXI DMA S2MM → PS DDR → PS软件/主机。[R5、R6、R7]

本包rtl/scanner_capture.sv只实现同一时钟域的12周期标签延迟与有限深度FIFO。它不是引脚级AD9268接收器、异步FIFO、抽取滤波器、完整扫描状态机或DMA驱动。随包测试平台检查256个真实仿真ADC测试码的顺序与标签，以及下游长时间停顿时的溢出报告。

```text
Icarus Verilog（在rtl目录）:
  iverilog -g2012 -s tb_scanner_capture -o scanner_tb scanner_capture.sv tb_scanner_capture.sv
  vvp scanner_tb
Vivado已配置命令行环境后（在rtl目录）:
  xvlog --sv scanner_capture.sv tb_scanner_capture.sv
  xelab tb_scanner_capture -s scanner_sim
  xsim scanner_sim -tclbatch run.tcl
```

也可直接运行rtl/run_xsim.bat或rtl/run_iverilog.sh。预期测试输出以PASS开头，失败会调用$fatal；本交付环境未执行这些外部仿真器，必须在本机确认。scanner.vcd可用于波形查看。

不能让下游TREADY直接暂停ADC。扫描还在继续时，ADC持续产生样本；FIFO只吸收有限停顿。超出容量必须记录溢出、停止接受该帧或按协议明确标记无效，不得悄悄丢样后继续拼成“完整帧”。

上板前硬性核对：J5/Bank35为3.3V；J6/Bank33为Vadj且默认3.3V，旧版J5引脚不兼容。裸片AD9268的1.8V CMOS不能默认直接接3.3V输入标准；应先确认模块是否电平转换、实际VCCO、DCO时钟能力与布线。[U2，第10页；R1]

所给网口PHY连接PL Bank35。使用PS GEM需要合适EMIO路径和GMII/RGMII转换，或设计PL侧MAC，不能假定烧入普通PS网络例程就能使用。[U2，第2、5页；R7]

board_clock_reference.xdc只保留已核对的M19/50MHz参考注释，未臆造ADC/SOS引脚。实际接线与输入/输出时序约束必须由模块资料和实测建立。

512 MB DDR并不意味着可以任意保存多份大图。上述单通道16位输出双缓冲占240.8 MB；两倍采样原始帧双缓冲占481.6 MB，再加操作系统/程序/描述符就可能不足。浮点密度图、标定图和临时数组也占空间，应优先按行块流式处理。

measurement_templates目录提供空CSV表头：scope_capture、geometry_calibration、density_calibration、afe_transfer、frame_integrity。它们不是虚构实测数据，也没有附带仪器控制或自动拟合脚本。应保留原始仪器文件，再在副本中统一单位。

识别参数时分开实验：固定激光与PMT增益测前端；固定前端测镜面位置；固定运动测密度；最后再做整机联合验证。只用一张最终图像反推所有参数通常不唯一，容易把几何误差误拟合为光学模糊。

校准应使用实测、重复平均的参考数据，并给出不确定度。当前程序使用合成、无噪声的白/遮光参考来验证算法，因此其标定条件比真实仪器理想，不能视为实际标定精度。

## 16 验证结果、验收指标与失败应怎样显示

本次默认教学算例实际生成128×256密度图、65,536个有效ADC样本。内部有效区域相对光学参考的密度RMSE为0.10627，MAE为0.04964；无效像素比例为0.0214%。这些是合成模型结果，不是实机测量或达标声明。

实际执行的合成阶梯密度结果：模拟带宽与光子噪声保留在输出中。

默认深密度区表现较差，是示例光子预算与非线性动态响应的真实后果，不应在预览图中通过平滑或对比度拉伸隐藏。应同时检查密度阶梯的偏差/标准差、无效掩膜和饱和计数，而不只看全图RMSE。

14项自动测试覆盖：几何一致性、对数反演、量化误差、透射率卷积、常量PSF、流水线标签、FIFO积压、理想端到端、随机种子复现、采样率/窗口合法性、滤波DC、行样本数和小端原码格式。测试通过说明实现与这些契约一致，不证明整个物理模型已正确识别。

对照实验在results/ablation.csv：关闭光子噪声、改变对数带宽、增大光斑、增加杂散光和电流相关带宽。注意：增大光斑可能使“相对已模糊参考”的RMSE降低，却同时损失真实分辨率；不能据此判断光斑越大越好。

建议与用户需求一起确定验收门槛：几何误差（像素或µm）、各密度点的偏差/标准差、MTF、饱和/无效率、行/帧完整性、吞吐和运行稳定性。示例“0.1像素”或“0.02OD”只能是拟议目标，不是引用的行业合格标准。

与光子飞行有关的纯延迟在模型中按光程/c加到PMT渡越之前；机械扫描与ADC采样仍是并行进行。对数与滤波响应本质上混合邻近位置的信息，不能仅用一个固定“从激光到像素的总延迟”替代。

当前连续送片校正是一阶近似；镜面偏差、三次畸变与行内Y位置完全耦合时，需要对每个样本保留真实(x,y)，做二维不规则重采样。本模型没有完整编码器丢脉冲、SOS漂移、帧丢失或网络协议仿真；这些应加入后续故障注入。

最有价值的下一步是把一条真实扫描线接入同一套分析：取得ADC模块/前端资料；对一块已知密度阶梯同步记录SOS、模拟波形与原始ADC码；先拟合静态电流/电压/密度关系，再拟合不同光强下动态响应，最后替换几何参数。

完成这一轮后，再决定是否需要更复杂的光线追迹、模拟器件模型、双量程/多次曝光和更高带宽。先让仿真能解释实测误差，再用它预测修改的收益。

本包没有许诺不可获得的厂家资料。已知原件、可运行代码、原始仿真输出、测试记录、空测量表和官方资料入口均随包给出；缺少的专用电路与器件资料已明确列出，不能由照片可靠补齐。
