从一束光到一个像素：逐采样时刻观察器

数据来自本资料包的 Python 行为仿真，不是实机测量。下方只逐时刻显示第 0 行采集窗口；空白行周期、预热及标定见 frame_events.csv。光路为功能示意，不代表已复原透镜和反射镜的机械坐标。

1. 信号链与时间

激光 → 准直/整形（待确认） → 多面转镜 → 扫描聚焦系统 → 底片透射 → 集光系统（待确认结构） → PMT → 对数模拟前端 → 滤波/差分驱动 → ADC → FPGA 延迟标签/FIFO → 图像

蓝本采用单波长、单路灰度采集；PMT 高压模块是供电支路，不在光路中。
