# 模拟前端 SPICE 入门工程

在本目录运行 `ngspice -b behavioral_log_frontend.cir`，读取输出 `frontend_trace.txt`。
这只验证“电流→静态对数→有限带宽→二阶低通”的传递关系，不是现场电路的晶体管级模型。
`Iphoto` 在约 38.4 μA 和 38.4 nA 之间切换；后者代表透射率下降三个数量级。
`Vsense` 是零伏测流源，其电流单位为 A；不能把节点电压当成 PMT 电流。
RLC 是数学实现，不是推荐的模拟板 BOM。没有温漂、输入偏流、实际芯片稳定性、
高压分压链、暗电流统计、驱动器压摆率或真实 ADC 输入电容。

本次环境没有 ngspice，故此文件未在 ngspice 中执行。语法与运行结果须在本机确认。
对数放大器不是 LOG112 的替代模型；LOG112 只是资料中的原理参考，未识别为实机型号。
真实带宽必须在最亮/最暗电流、不同温度、不同跳变方向下测量。
