14项单元/端到端测试全部通过，原始日志在examples/python_test_log.txt。

包含未补偿模拟延迟与噪声，故不会因静态校准而自动得到低误差；这不是已通过实机精度验收的模型。

AD9268参考模式256×32已运行：50MSPS、5样本/像素、12拍参考；相同误差指标为 0.572304 D。
