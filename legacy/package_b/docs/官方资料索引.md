## 原厂/项目官方资料

https://www.ti.com/lit/ds/symlink/log112.pdf

[E5] Analog Devices：AD9268 数据手册 Rev. A。重点读第4页输入范围/共模/数字电源，第9页速率下限和12拍/12.5拍延迟，第10/11页时序图，第26–33页模拟输入、时钟和输出，第34–40页测试码/SPI。
https://www.analog.com/media/en/technical-documentation/data-sheets/AD9268.pdf
https://www.analog.com/en/products/ad9268.html
