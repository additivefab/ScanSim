# 模型边界、数据语义与建议验收

## 实现层次

系统模型是随机光电行为模型，不是实测识别模型。原始输入是光密度D；PSF作用于T=10^-D。
光学用右端点离散求积；偶数内部过采样使ADC采样中心落在内部时间网格上。
PMT电子数在内部时间箱中服从泊松分布，倍增用条件Gamma随机量产生过量噪声；
暗电流视为等效光阴极电子来源。真实暗电流可能有不同物理起源，本包不区分。
纯延迟用线性插值近似，会带来有限步长影响；噪声波形不能逐像素跨步长比较，需比较统计量。

PMT和对数响应用常数极点，抗混叠用二阶Butterworth数字近似。真实对数响应在弱光下可能不同；
这些示例滤波器未被证明满足任何实机混叠抑制或稳定时间要求。
模拟输出噪声在ADC采样处独立加入，因此换采样率时应重新考虑其物理噪声带宽，不能盲目声称sqrt(M)提升。
ADC是理想量化器加采样时刻抖动；没有真实AD9268的INL、DNL、固有输入噪声、温漂、参考噪声和板级扰动。
ADC物理接收/DCO、数据格式和SPI由实机单独验证。

## 有效时刻与坐标

每行SOS时刻=j*Nline/fs。ADC中心时刻=(k+0.5)/fs；k是行内采样序号。
模型的x=0定义为第0个最终像素的中心，所以第一组子采样可能出现小的负x，这不是数组越界。
输出标签延迟L拍，模拟带宽不通过这个标签延迟被消除。
`phase=0`标记每行第一个ADC记录点所属的SOS阶段，精确SOS时间见line_events.csv。
M>1时输出像素标签重复M次；子采样号=(k-L-Npre)%M，仅在延迟后的valid为真时有意义。

## 图像和校准

原始码以little-endian u16保存，offset-binary语义是本模型假设；实际AD9268可能配置为补码或其他格式。
M>1时raw_codes TIFF宽度为Nx*M。重建后图像才是Nx×Ny。
校准文件使用模型已知的静态暗电流、平场、对数斜率和驱动参数，不模拟真实标定噪声、不完成实测拟合闭环。
`reconstruct_capture.py`会拒绝把MODEL校准默认为真实校准；演示时需显式加`--allow-model-calibration`。
校准平场必须与增益、波长、高压、温度、积分策略和扫描方向相匹配。

## 验收分层

算法回归：理想模型误差受ADC半LSB约束，行数/列数/标签必须完全匹配；本包已有自动断言。
数值收敛：关闭随机噪声后逐步减半步长，比较8/16/32/64倍等；不能只证明公式正确就声称动态仿真精确。
硬件接口：用ADC测试码验证位序、通道、采样边沿、时钟域、长时间误码和复位恢复。
系统定量：由用户目标确定D范围、允许密度偏差/标准差、MTF、几何误差、速度和可接受的重扫率。
不要把任何演示参数或测试门限写成行业标准。

## 需继续补的模型

真实镜头处方与散斑；逐面扫描误差；输入/温度相关对数动态；PMT空间电荷和恢复；
实际电机与编码器；真实ADC噪声及输入耦合；双通道半周期差；AXI/DMA/DDR和网络错误。
本包是这些工作的可扩展基线，不声称已经全部完成。
