## 本轮落实：有界波形查询

`GET /runs/{id}/traces?signal=…&start=…&end=…&pixel_width=…` 保持单信号窗口接口。
请求坐标是运行的模型细步，pixel_width 为 1..4096 整数；非法窗口返回 400，完全处于运行外
返回 not_computed，部分重叠时明确裁到真实数据范围。避免负索引悄悄读到数组尾部。

ADC 只在样本数不超过 2×pixel_width 时返回原始点，否则返回至多 pixel_width 桶。
模拟摘要不足以满足载荷上限时，从已记录摘要继续合并；没有原始记录的细视图仍返回 not_recorded。
每桶保存 min/max/first/last/count，只有显示用途，既不进标定也不进重建或评价。
对于只能按已有摘要块取数的边缘，返回真实 support_start/support_end 与 boundary_extra，
不把窗口外的极值冒充精确发生于所请求区间。

first_step/block_steps 定义每个显示桶在模型时间轴上的位置；ADC 原始点使用点标记与保持阶梯。
采样周期按整数分子/分母传输，首末采样时刻与样本序号按字符串传输；模型细步时间也按有理数
与 BigInt 计算，页面不再把四倍模拟细步直接称为一条新 ADC 观测。
样本谱系明确 host_arrival_time 为 null/not_recorded，待真实队列记录接入后再补，不能用零代替。

本轮还修正原页面的全局“最后回复序号”：事件请求先完成时，不应把另一个面板正常的较早请求
作废。现以查询类型和信号分别跟踪最新请求，并以视图代数阻止切换视图前的回复回流。

## 接续顺序

实际 HTTP 基准在干净提交 `e9a13a2` 上完成，每种查询连续请求 20 次；输入为假设参数的
6 行 demo（60,000 模拟细步、15,000 ADC 样本）。ADC 总览返回 31 桶、1657–1658 字节，
模拟总览返回 31 桶、2002–2003 字节，ADC 细窗返回 4 个原始码、530–531 字节。
首请求分别为 1.122、1.246、0.511 ms；其余 19 次 P95 分别为 1.087、0.784、0.767 ms。
这是本机内存运行的 HTTP 请求、读取正文和 JSON 解码时间，无响应缓存，未控制系统磁盘缓存。
不含仿真建立、检查点回放、浏览器绘制或整页交互；不能据此宣称达到 150 ms/30 FPS。
完整数值见 `bounded_trace_http_benchmark.json`，版本、输入哈希与判据见
`evidence_runs/2026-11-12_bounded_trace_http/record/`。

1. 保持 P0 物理约束；继续低光阶跃/独立标定及公共/独立随机源检验，避免用交互效果包装模型能力。
2. 补齐全链路的数字状态与控制事件检查点，以及真实主机到达和队列账本，作为样本跟踪的来源。
3. HTTP 成像草稿已合并观测坐标、查询和时间合同；继续浏览器视觉验收、完整光路/逻辑联动以及真实队列账本。
4. 再完成三层时间轴、完整交互与实测导入。三维仅渲染，不改变模型；框架建议不等于必须换栈。

当前采用标准库本地服务与原生 SVG/Canvas，符合原文允许的首版路线。没有新增 React、Three.js、
FastAPI、Arrow 或外部服务依赖。既有 V5 架构及其真值隔离规则保持为实现依据。
