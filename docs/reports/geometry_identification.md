```sh
zlscan ident --geometry-fit geometry-fit.json --out geometry_result
```

输出run.json、geometry_residuals.svg及PNG。原始文件和注释均保留hash；输出目录不覆盖。
输入合同见 `docs/dev/03_contracts.md` 的观测几何辨识一节。

逐面拟合 `target_x = a + b*u + c*u^3 - slope*dy`。u来自声明的样本列，
phase来自同一码流的可观测传感器事件；网格斜率为0，斜线斜率来自尺寸参考。
报告四参数的秩、可辨识组合、零空间、条件边际置信区间、协方差与相关性。
网格独自不能确定dy；仅有同一斜率的斜线不能分离a与dy。不可辨识项不输出猜测数值。

置信区间条件于固定样本位置/斜率和声明的独立已知目标x标准不确定度，
不传播标记定位、共同尺寸证书、镜面分组错误或模型偏差。没有将组合误差拆成器件误差。
不自动生成合格标定，不把拟合结果升级为实测；hard_acceptance_eligible始终false。

原始码流、捕获描述及注释摘要需匹配，同一配置的捕获才允许联合拟合。
重复原始源或采集身份拒绝。原始样本缺口不补，失锁或同一行换时期的后段不借原面号。
对所选通道单独恢复相位。注释位置的两邻近整数样本都须实际交付。
有限软件资源上限与实际硬件能力无关，未从未到位资料猜出参数。

验证捕获不参与拟合，预测只在fit范围及可辨识方向内进行。
逐面留出设计秩不足时报告incomplete_coverage，不能靠无斜线的低残差“验证”送片偏移。
导数非正则invalid_geometry。失配、不可辨识和覆盖不足均保留报告并返回非零。
独立源摘要/采集身份检查不证明实际物理独立性，报告明确这一限制。
