# ADC 输出链路的增量状态与检查点

2026-11-12，S3-T14 的 ADC 链路组件。传输组件已独立实现检查点；
当前仍未形成包含采集、控制、模拟状态和写盘游标的原子整链检查点，D026 保留。

## 实现

`adc_link/stream.py::StreamLink` 接受连续的 `ConvertedSamples` 块，保存流水线在途码字、
四个时刻、源 run/branch/session/epoch、源序号、水位、溢出偏移历史/前瞻以及已就绪未取的输出。
编码、位序、通道序和时间运算调用批处理链路的同一实现，保留原向量化批处理入口。

典型顺序是：

```python
link = StreamLink(domain, config, channels)
link.push(sample_block)
link.advance(last_sample_tick)
outputs = link.drain()  # 调用者保存/消费，不在 link 内累积全程历史
blob = link.checkpoint()
link = StreamLink.restore(domain, config, channels, blob)
# 继续提交连续源序号；明确有限输入结束后排空在途数据
link.finish()
link.advance()
outputs += link.drain()
```

时期切换不重置旧在途数据；每一输出仍携带采样时的时期。时钟、通道顺序和源身份不能
静默更换；源序号跳变或关闭水位之前的输入会被拒绝。当前不模拟硬件复位清流水线，
控制协调器接入时需要定义复位丢失记录与新时期行为。

增量入口要求显式的流水线和传播延迟，不把未知值当作零。
`advance(t)` 不允许发布所需溢出前瞻尚未提交的样本，拒绝时状态不变。
`finish()` 声明有限输入边界后，缺少来源的 OFL 值保留 False 以兼容原批处理数值，
同时以 `overflow_valid=False` 标明没有该观测。正偏移首端和负偏移尾端均有此标记。
提前 OFL 的配置需要调用者在发布前提交相应前瞻，功能模型不证明硬件可因果实现该偏移。

检查点格式为 `zlscan-link-checkpoint/1`，绑定版本、配置、时钟、通道及内容校验和。
样本序号和时刻按十进制字符串保存。`ready()` 返回独立只读快照；保留未 drain 输出会增大
检查点，持续提交但不推进也会保留全部输入，不能宣称这些用法具有恒定内存。

## 同轮修正

- `LinkOutput` 与 `receive()` 传递原 run/branch/session，避免解码后回到默认身份。
- 接收端 OFL 偏移改用非循环校正，并传递有效位；不再把首段标志循环拼到尾段。
- 有理数时钟的流水线输出和上升/下降捕获边按完整半周期计数计算，只取整一次。
  例如 125000003 Hz、源序号 4294967291、25 半周期延迟，在不加相位时，旧算法得到
  34359737603365 ps，新格点为 34359737603366 ps。两段分别取整使旧值早 1 ps。
- 时间加法和捕获格点越过有符号 64 位 Tick 时拒绝，禁止 NumPy 静默回绕。

这些时钟、延迟和刺激均属于假设功能模型，不是 AD9268 实际配置或引脚时序签核。

## 验证范围

48 种分块大小、捕获沿及正/负/零 OFL 偏移组合，逐块保存恢复后，码字、四时刻、
OFL 值与有效位均与完整批处理一致。额外检查跨时期在途、未取输出、只读查询、
拒绝输入的原子性、损坏/配置失配、空输入、有限边界及 Tick 溢出。
有理数时钟另用独立的双倍频率时钟与逐边搜索核对，不以链路自身公式作唯一依据。

10,500 样本持续输入测试及时推进/drain，最多 14 个样本在途；检查点小于 10,000 B，
稳定区间的大小变化小于 200 B。此测试的队列配置和延迟固定，不代表任意偏移均有相同开销。

`tools/audit_link_checkpoints.py --out <new-directory>` 将繁忙流水线写文件后，在新 Python
进程恢复并提交其余输入。它验证双通道位序/码制、上升/下降沿、±5 和零 OFL 偏移、
32 位计数跨界、超过 2^53 的 Tick、未读输出与跨时期身份；不验证采集窗口、队列或写盘恢复。
