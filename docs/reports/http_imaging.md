# HTTP 成像与源样本联动

S4-T09，2026-11-12。实现与行为测试通过；浏览器视觉和真实交互验收未执行。
当前 Work 设置禁用了本地浏览器。此功能不提升任何物理模型或硬件能力的证据状态。

## 使用

用当前版本执行 `zlscan reconstruct`，输出新增 `lineage.json`，保存重建实际采用的
扫描向坐标、逐行位置、源块身份和时钟，并在 `run.json` 中绑定图像与谱系 SHA-256。
只读服务支持旧版无谱系工件的图像，但不为其猜测样本来源。

建立注册清单，路径相对于清单所在目录：

```json
{
  "runs": [
    {"id": "sample-a", "reconstruction": "reconstructed-a", "raw": "sample-a/observable/raw.zlraw"},
    {"id": "sample-b", "reconstruction": "reconstructed-b", "raw": "sample-b/observable/raw.zlraw"}
  ]
}
```

运行 `zlscan serve --images registry.json --port 8765`。页面选择主运行和可选对比运行。
瓦片是原分辨率，每张最多 256×256；可切换质量掩膜。灰度显示范围为 0–4 OD，
像素读数保留原始密度，不修改数据。点击主图像素按源样本身份跳到其首个实际贡献样本，
显示所有贡献样本、采样时间范围、双线性权重和无效原因。对比图使用自己的时钟，
点击它不会将其时间误作主运行时间。同像素并排不声明完成几何配准。

若要检查当前期望的标定，可在注册项增加 `expected_calibration_id`；
若要检查当前完整采集绑定，可增加符合 `Binding` 合同的 `expected_binding`。
失配时页面显示 `CALIBRATION_MISMATCH`，瓦片密度为 null，像素谱系禁止用于有效结果。
原始 ADC 仍可作为观测码查看；它不因密度标定失效而变成假数据。

## 合同与验证范围

- 谱系从重建保存的实际坐标重算，覆盖延迟补偿、逐面非均匀映射和跨行贡献；不读取真值。
- 无效像素报告几何支持候选，归一化权重为 null。缺行不制造样本编号。
- 时间与绝对样本序号以十进制字符串传输。原始码含缺口时为 null，显示曲线在缺口断开。
- 大窗口波形按显示预算汇总，保留极值、首末值、位置计数及另列的实际记录计数。
  约两百万样本位置的稀疏测试仅返回至多 31 桶，保留空桶与峰值。
- 注册检查文件 SHA-256，查询检查源身份变化；原始块读取另核对载荷 CRC。服务不修改工件。
- API 测试逐像素用权重复算线性透射率，与保存图像比较；Node 执行页面实际函数，检查
  超过 2^53 的样本原点、像素跳转、瓦片/运行回复乱序和缺样绘图。它们不是浏览器渲染测试。

`tools/verify_image_http.py --registry registry.json --out report.json` 可对有谱系和原始码的
注册运行执行真实本机 HTTP 查询，并用独立 ZLRAW 逐块读取核对选中源样本的 ADC 码及采样时刻。
它不启动浏览器、不测试 FPS，也不证明实测来源、前端响应或高密度能力。

完整模拟/数字检查点、主机到达时间、功能光路、逻辑轨道与纳秒游标仍有未完成项。
旧 nominal 工件来自历史假设模型；本轮重读它们不能充当新物理模型验收。

## 正式复跑结果

干净提交 `6586aa6` 上重新读取历史 nominal 原始观测和 SIMULATED 标定，生成
40×12 与 20×12 两个重建结果。有效覆盖分别 97.5% 和 95.0%。40×12 与历史重建
掩膜逐像素一致，有效区密度最大差 0 OD（验收容差 1e-12 OD）。

真实 HTTP 查询验证两种网格以及故意失配的第三注册项；各选一个有效像素，分别找到
24 和 48 个贡献样本，归一化权重和为 1。其首贡献原始码均为 8793，经另一条 ZLRAW
逐块读取路径核对；采样时刻也按源时钟独立核对。总览各返回 31 桶，未记录位置
20,493 个，包含数字采集窗之间的时间，**不能把该数当成传输丢包数量**。

输入、代码、环境、命令与判据在 `evidence_runs/2026-11-12_http_imaging/record/`，
详细查询见 `http_imaging_verification.json`。三个注册项的服务查询前后，原始码、图像、
谱系及清单哈希均不变。随后另用实际 `zlscan serve --images … --port 0` 启动进程，
读到三个运行和有效像素的 31 个支持样本，并在测试结束后停止服务。
这些验证不覆盖页面视觉、真实点击或绘制时延。
