# 已有物理运行工作台（S3-T16/S3-T14 部分）

2026-11-13。仅保存的模拟运行与 HTTP/重放软件验证，不是实机或浏览器视觉验收。

```bash
zlscan run --mode physical --lines 3 --out physical_saved
zlscan serve --run physical_saved --port 8765
zlscan replay --run physical_saved --start-step 11000 --steps 100 --out replay_saved
```

--run 与已有 --images 互斥；不指定则仍为演示。--run 模式只读注册该目录，
不新建 demo、不重新生成整段模拟、不制造演示队列停顿。新运行将全部
ChainConfig、场景 NPY 与模型/配置摘要写在 truth/workbench。保存配置、
源码、检查点、可观测元数据和部分模型链路时间均有指纹；场景/源码用
只读 mmap，配置使用固定构造类型和 JSON，不使用 pickle。
配置/场景包含仿真真值，明确 ORACLE_ONLY，不进入标定或重建输入。

支持当前单通道、完成写入的 physical 目录。新运行可恢复自定义种子、
功率、场景、时间线与脉冲；旧目录只有配置哈希精确匹配当前 demo/nominal
时才兼容，标为 legacy_unfingerprinted。旧自定义配置缺失、旧模型版本、
双通道流式/数字/标定等其它目录布局仍不支持，明确拒绝，不猜参数。
CLI replay 默认同样读取保存配置；显式 --preset 作为一致性要求，
与保存配置不符则拒绝。该配置包是研究前向链的记录，不是通用硬件配置格式。

载入时核对源 ADC 数量、类型、配置摘要、检查点位置/模型及摘要、
ZLRAW CRC/身份、capture 摘要/绑定、时钟与位宽。未记录的探针没有持久波形，
细步 state/replay 从原检查点只读计算并标 REPLAYED；没有检查点或当前位置
之前无检查点即未记录，不生成默认起点。载入不调用 Chain.advance。
配置/检查点在内存保留注册快照；mmap/交付文件变更时拒绝查询。
输入目录要求完成写入，不是运行中跟随尾部或未知长度在线捕获入口。

研究视图的完整 ADC 源码来自 truth/source_codes.npy，标 ORACLE_ONLY。
实机可观测视图 ADC 只读实际交付 ZLRAW；窗外、未交付等位置为 null，
粗视图保留 min/max/首末及有效计数，部分支持的区间使用已有前端标记，
不从源码填补。missing_count 包括未保留源位置，不全部等同于丢包。
仿真队列诊断只在研究视图；模拟事件位置未保存时标为未记录，不能把空事件列表当作没有事件。仪器视图不执行源模型重放。

新目录另存第一批少量参考样本的模型链路时间，研究视图可逐项查询原值。
它们标 SIMULATED/ORACLE_ONLY；未登记样本、仪器视图及主机到达时间
仍为未记录。没有创建默认 24 半周期等链路去冒充历史运行；自定义数字
链路延迟的已存时间也原样返回。这不是完整逐样本链路历史。

manifest 标 read_only/loaded_from_saved，页面显示只读来源并禁用分支。
服务关闭会先等待查询线程结束，再退出保存工件上下文释放 mmap。
原始配置、码流、检查点和其它输入文件不改，不写回重放值。
ADC 源码 mmap 不等于全部状态内存有界：场景/摘要校验与检查点索引仍
随有限保存任务增长；大场景配置哈希及全部检查点载入性能尚未验收。
