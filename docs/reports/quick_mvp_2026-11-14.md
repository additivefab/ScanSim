# ScanSim Quick MVP

2026-11-14。Quick 是独立的 `SIMULATED / APPROXIMATE` 交互演示路径，不改变原研究链路、硬件画像或正式文件合同。

## 使用

```bash
.venv/bin/zlscan quick --preset demo80 --out results/quick_demo
.venv/bin/zlscan quick --serve --out results/quick_ui --port 8766
```

打开 `http://127.0.0.1:8766/` 后，点击“计算 Quick Run”。页面支持内置测试底片、参数修改、PNG/TIFF 用户图像上传、计算、播放/暂停、行滑块、上次/本次结果对比、预览图、当前行 CSV 和运行 JSON 下载。也可以用 `--input path/to/image.png` 或灰度 TIFF；`.npy` 输入按密度数组读取。

## 当前实现

- 普通图像按显式密度映射；光学模糊在透射率域用整幅 `gaussian_filter` 预计算。
- 采用旋转多面镜/f-θ 与连续送片的近似行时序；每个输出像素一个代表测量，不生成真实 ADC 细步或数字链路。
- 积分筒局部响应、等效 PMT/对数前端、一个一阶时间常数、演示电压噪声和理想 ADC 均向量化计算。
- 输出为 `quick_run.json`、`arrays.npz`、`preview.png`、`selected_line.csv`，并明确 `origin=SIMULATED`、`fidelity=APPROXIMATE`、`validated_for_hardware=false`。
- 演示服务同时提供 `demo` 与 `demo_offfilm` 成对运行，用于观察片外照明门控的近似影响；这不是实机数据。

## 验证

- Quick 单元/CLI 测试：5 项通过，包含灰度 PNG 输入。
- 六个预设 `ideal`、`blur`、`stripe`、`tail`、`noise`、`saturation` 均实际生成独立 run；饱和预设产生约 21.97% 饱和掩膜，噪声预设产生约 16.06% 无效掩膜。
- Quick 与原工作台 API 回归：24 项通过。
- 实际页面复核：默认计算完成并显示 `SIMULATED / APPROXIMATE`；修改演示噪声到 0.05 V 后重新计算，显示上次/本次配置差异、同一显示范围的对比预览、有效掩膜比例、CSV 和运行 JSON 下载链接。
- 提交 `1e04361` 的六目标 CI 已通过：[run 43555839419](https://github.com/additivefab/ScanSim/actions/runs/43555839419)，回执在 `evidence_runs/2026-11-14_quick_mvp_ci/record/1e04361_acceptance.json`。

## 边界

Quick 不模拟真实 ADC 时钟、FPGA/FIFO、ZLRAW、寄存器、硬件响应、精密散粒噪声、断电恢复或正式标定；它只用于快速调参、观察扫描过程和导出演示结果。
