# 条件辐射均值、采样方差与留出验证

2026-11-13，S6-T03软件路径，D082。本轮没有新增实测，也不关闭阶段3–7门槛。

```sh
zlscan ident --radiometry-fit radiometry-fit.json --out radiometry_result
```

输入格式见 `docs/dev/03_contracts.md` 的条件辐射辨识一节。
输出run.json、radiometry_residuals.svg和PNG；不覆盖已有目录。
只处理明确声明为线性读出的A/V数据及原始时间窗口；不把对数码先平均再反对数。
没有自行证明这些电压已线性化或未饱和，必须保留操作者的可追溯说明。

均值模型为 `y=b0+q*(s+P*g_direct*T+P*g_glare*S)`。
显式遮光状态q区分暗基线与开光常数项，中心/周边透射率T/S区分直达/宽域耦合。
常数杂散不等于随功率缩放的项；s只是输出域的等效量，不推断未经测量的杂散瓦数。
均匀场只能识别增益和，缺遮光只能识别基线与开光常数和。
报告条件参数区间、相关性、可辨识组合及零空间，未知分量不填默认值。
眩光比仅为该中心/周边协议的delta-method比值，不是从数据恢复完整宽尾核或物理PSF。

窗口噪声给出样本方差、lag1、半窗均值差及条件于iid Gaussian的chi-square区间。
门禁不能证明白噪声、正态性或物理独立性；零方差不被当成确定的零噪声模型。
方差随拟合均值的线性候选使用样本方差权重作矩拟合，属于名义近似。
均值模型条件于声明的已知均值sigma，方差模型条件于估计的均值与plug-in方差误差，
没有传播两者联合误差、光学控制定位误差、共用证书或仪器响应不确定度。
这里的方差不是噪声谱密度，不分解暗事件/读出/过剩噪声，不能证明时间网格收敛或4.5D能力。

支持单次采集的多个非重叠fit窗口，保留实际样本范围。
源/元数据hash、采集身份与声明的设置引用一致性均核验；重复样本及fit/validation共源被拒绝。
时间容差只用于原采样声明核对，不放大选取窗口。不同捕获不宣称逐点同步。
fit假设失败不发布模型推断；validation单独失败不改变fit参数，只报告验证假设失败。
留出不重拟合，超fit凸包或未覆盖参数方向时不外推或宣布验证成功。
负耦合、非正方差或负方差斜率保留拟合原值并标记候选不可接受，不静默夹紧。
该约束针对指定候选，不意味着真实硬件不可能有其他响应模型。
候选采用随光强增加的正响应约定；反相读出需有独立依据的符号/线性化转换，
不能仅凭电压单位假定符合该约定。引用与摘要不证明实际设备设置或声明真实性。

`tools/audit_radiometric_identification.py` 独立生成线性读数和声明，实际调用CLI并新进程重拟合。
七个算例包括正常、均匀场、缺遮光、相关噪声、留出方差失配、单采集多窗口及验证相关噪声。
这些是条件统计软件算例；不是物理探测器噪声生成器或实际M04/M08。
生成器参数只给评价器，辨识器不读truth或正向链状态。
每窗512点，均值/方差参数评价界限预设为4个报告sigma，开发态实际最大为
1.24567249883388个；留出均值容差3e-10 A、方差比上限1.6。
这不是实际仪器精度或重复试验覆盖率，尤其方差矩区间只是所声明的近似。
