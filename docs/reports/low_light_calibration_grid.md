2026-11-12，S3-T07/S4-T02，D049。针对用户技术评审尚未完成的低光动态和独立标定残差，
新增可复跑实验工具；不改变 demo/nominal 的物理参数或高密度适用性限定。
所有参数、靶标和时间均为 ASSUMED，无实机数据。

## 预声明实验

- ADC 1 MHz、16 bit，研究电压范围 −1..2.5 V，包含对数下限；避免将原 demo 的低端 ADC 削顶
  误当作带噪对数响应。不是 AD9268 板卡的已确认工作点。
- 对数前固定极点 20 kHz，对数后 30/50 kHz；倍增因子 F=1，暗电流 0，数值下限仍为模型现有值。
- os=4/8/16/32。每网格 8 次独立重复；阶跃、拟合、验证及网格间的 seed 全部分离，共 96 个 ADC 文件。
- 阶跃在初级电子率 1e6/s 与 1e5/s 间交替，预热 512 个 ADC 样本，每方向 256 样本，循环 64 次；
  物理状态连续。每次重复先汇总循环，再以重复实验为统计单位，不把相关时间点当独立样本。
- 参考为暗、白（1e8/s）及 D=0/1/2/3/4，验证用未参与拟合的 D=0.5/1.5/2.5/3.5。
  每个稳定曝光保留前有 512 样本的明确预热；用静态均匀光强模拟参考透射率。
  这是定点光度链实验，不是完整阶梯扫描、空间几何或局部积分筒响应验证。
- 参考为 16 行、每阶 64 列；暗/白宽 320 列。验证每档 16×320 个采样，按声明分析列在线性域合并
  重复测量后取密度。列只是固定分析 bin，不从前向模型读取真实位置作为重建坐标。

采样数据落为 ZLRAW，保留实际源序号与预热缺口、CRC、采样时钟和测量窗口。
分析重新读取文件；拟合只接收参考 ADC 数组、已知参考密度和研究绑定，验证标签只在重建之后算残差。
保存 SIMULATED 标定文件，重建仍调用公共的码→线性化→扣暗/归一化→合并→密度路径。

## 两种标定臂与绑定

每个数值网格拟合自己的参考，另将最细网格的同一拟合用于全部网格的独立验证，防止重新标定
吸收网格偏差。研究以显式命名的同一物理假设仪器绑定，os/seed 另外保留；该绑定刻意不能匹配
正常 run 配置，普通生产标定的 require_applicable 检查未放宽。不能把研究标定拿去冒充设备标定。

每个最细拟合在同编号重复下共享给各网格，固定标定臂的差值据此配对；其他比较按独立重复。
每个像素保留所有无效原因及 NaN；偏差/RMSE 标为仅有效区，另报完整分母和无效比例。
没有有效点时残差是 null，不是 0，也不删掉该重复后宣称覆盖完整。

## 统计判据与边界

预声明数值研究精度：均值差 5 mV、固定窗功率比 1.25 倍、偏差差值 0.02 OD、
无效比例差 2 个百分点。它们不是实机合格阈值。差值区间完全落在等价带内才报告 equivalent；
否则分别报告超界、inconclusive 或重复不足，不把“未发现显著差异”当等价证明。
阶跃和标定分别对 18/48 个比较作 Bonferroni 控制。

均值与对数功率采用重复统计量的 t/Welch 近似区间；无效比例采用 [0,1] 有界的 Hoeffding
保守区间，配对差为 [-1,1]。零观测也有不确定性；8 次重复通常不足以证明 2 个百分点等价，
必须明确保留证据不足。不能用相关像素数量冒充独立重复数来压低区间。
固定窗谱只取各半周期后 128 样本，常数去趋势，7.8125 kHz 频率格；求和至 50 kHz。
未分辨的低频功率不包含在该有限窗指标中，不能叫完整低频噪声谱。

低光下的有限光子、对数下限和对数后滤波可能使现有参数化拟合不适用；观察到的独立残差
不应一概归因于数值网格，也不能用已知前向参数替换观察拟合以消除它。
研究只覆盖所声明的固定条件，不证明连续极限、全部参数范围或真实密度能力。
