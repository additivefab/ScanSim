# S5-T03 宽尾眩光候选软件路径

2026-11-13，D083。该机制默认关闭，未引入新依赖。

`PsfConfig` 增加 `glare_weight`、`glare_fwhm_x_m`、`glare_fwhm_y_m`。
在透射率域计算核心和宽尾两个归一化 Gauss–Hermite 卷积，再做凸组合：

```text
T_eff = (1 - glare_weight) * G_core[T]
        + glare_weight * G_tail[T]
```

当权重为零时保留原核心调用路径；任一启用宽尾配置要求两个正宽度，权重越界拒绝。
常数透射率在两个分量和混合后保持不变，边缘算例能看到宽尾对核心响应的影响。

测试覆盖默认关闭等值、常数场能量守恒、边缘开关影响、非法配置、节点收敛、
核心透射率域而非密度域卷积和 47 项既有链/真值回归。
