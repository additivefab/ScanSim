ADC/采集/传输子链、真实在途载荷、ZLRAW 序号/偏移与诊断日志游标。

## 文件合同

新输出独占创建；已有路径不覆盖。`RawWriter.resume()` 校验会话、完整提交前缀 SHA-256、
头/载荷 CRC、结构边界和下一序号，原位恢复保留文件 inode。扫描使用有界读块，
完整前缀验证的时间随已有文件大小增长。操作系统文件锁与生产者互斥锁防止合作写者重入；
不把它们当成抵御非合作外部写入的文件系统事务。

输出文件 flush/fsync 后生成配对检查点，再以同目录临时文件、fsync、原子替换发布；
POSIX 另同步目录。任一写入或发布失败使记录器失效，不能继续发布新检查点。
发生未提交尾部时，原位恢复明确拒绝；显式 `branch_directory` 只复制已校验提交前缀，
在新目录续写，保留故障原件与旧检查点。没有隐式截断、删除或重放已提交包。

ZLRAW 保留模拟 ADC 观测代码；诊断日志包含精确模型队列占用和丢失，整体标为
`origin=SIMULATED, visibility=ORACLE_ONLY`，只用于研究诊断与评价，禁止交给标定/重建。
末级完成时间不冒充主机到达。日志逐字节相等的比较保持相同生产提交批次；
数字载荷的分块无关性另由组合子链测试覆盖。

## 验证范围

单元测试覆盖独占文件、活跃锁、同尺寸外改、短文件/破损前缀、会话与序号失配、
旧检查点重复重放拒绝、部分日志写入失败、分支保留原件，以及生产期间检查点互斥。
故障实验改为每次创建独立目录，保留各次输入，适应不覆盖的 writer 合同。

`tools/audit_recording_checkpoints.py` 在新 Python 进程打开实际已有文件并续写；
两沿 × 有/无停顿 × 正常关闭/突然进程退出，共八组。
突然退出用 `os._exit(86)` 跳过关闭与新检查点发布，再验证旧根拒绝尾部、分支恢复；
不是物理断电测试。检查 raw/journal 的提交前缀和最终全部字节、摘要、CRC 与序号。

本机 macOS 执行；Windows 锁分支依据 [Python 官方 msvcrt 文档](https://docs.python.org/3/library/msvcrt.html)
实现，但 Windows 执行未验证。磁盘缓存未控制，不外推为硬件吞吐、断电保证或界面时延。
