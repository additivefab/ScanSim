# 数字采集与组合子链检查点

2026-11-12，S3-T14。新增增量采集，并组合 ADC 输出、FPGA 窗口、传输和真实待发载荷。
完整系统的模拟状态、控制命令和外部写盘游标尚未纳入，不能据此关闭整链检查点门槛。

## 时间与身份

`CaptureClock` 统一上升/下降捕获边的有理数格点，与 ADC 链路使用同一实现。
`StreamAcquisition` 默认的源格点模式保留原 `acquire()` 的选窗语义，用于旧行为回归；
显式传入捕获时钟后，以输入实际 `capture_time` 定位 FPGA 边计数并选择窗口。
窗口的捕获起点与首个源样本序号分别保存，不将 ADC 流水线延迟悄悄抹掉。

采集保存未来同步、同刻排序序号、busy 截止、下一行号、未完成行和未取结果。
不同时期的数据保留为不同 `ConvertedSamples` 片段；混合时期窗口的 `epoch` 为 null。
首个位置在初始数据之前的窗明确跳过；输入尾部不足明确截断，后续行号不顶替它。
源格点选择时刻标为 `selection_time`，没有实际捕获记录时不制造 `capture_time`。
整数窗口计数、输入身份、源序号、水位和观测标志均有校验；拒绝输入不改写已完成状态。

## 组合接口

`engine/digital_pipeline.py::DigitalPipeline(domain, link, acquisition, stages, channels)`：

1. `schedule_syncs(ticks)` 在关闭相应时刻之前提交物理同步。
2. `push(source)` 提交连续源代码，推进到该块末采样时刻；依次驱动 ADC 捕获、窗口和队列。
3. `drain()` 取走交付包、丢失、同步诊断和占用轨迹，调用方负责保存。
4. `checkpoint()` / `DigitalPipeline.restore(...)` 保存恢复三个组件及队列中真实的代码载荷。
5. `finish()` 明确输入结束，排空 ADC/窗口/队列。EOF 排在此前关闭的 producer Tick 之后，
   不增加 ADC 行。交付时刻是最后声明队列级的完成时刻，不冒充主机到达时刻。

分包按同一窗口内连续源时期合并，因此不随输入分块大小变化。每包保留源身份、
OFL/有效位、实际捕获与选择位置；截断原因和缺少位置单独记录。检查点包括未取输出，
队列在途项必须与载荷表对应，不能只恢复包长而丢失代码。
`session_header(session_id)` 生成 SIMULATED ZLRAW 头，明确窗口基于捕获格点及该格点/链路配置；
文件中代码是解码后的 offset-binary，`link_model` 描述此前的模拟编码和接线。

及时推进并 drain 时，1,000 行、32,000 输入样本的测试交付 8,000 个保留样本，
检查点小于 20,000 B，所测大小变化小于 512 B。未取历史和一次提交的未来计划仍会占用内存，
不能把此测试外推为任意调用方式下内存恒定或规定全幅已提速。

## 同刻事件修正

发现并先复现：容量 1 B、速率 1 B/ps，两个项于 0/1 ps 到达。原批处理丢第二项，
分批提交却交付两项。原因是未来到达与已排定完成的相对入堆序号依赖提交时间。

现在同刻固定先到达、再完成，同类按原序号，保持原批处理语义并消除分块差异。
这不是实际 FIFO 同沿时序签核。传输检查点升级为 `zlscan-transport-checkpoint/2`；
旧 /1 需使用生成它的代码提交恢复，新版本不静默改变旧语义。原冻结 20 组批处理结果仍一致。

## 验证与限制

- 源格点分块/恢复与原批处理逐行对比，覆盖重复同步、重叠窗、帧前跳过及帧尾截断。
- 实际捕获模式验证上升/下降沿，明确源标签与捕获计数不同；跨时期片段和超过有符号
  64 位的源计数可保存恢复，Tick 本身仍遵守已声明的范围。
- 16 种组合覆盖两沿、四种分块及有/无停顿。每次恢复后的交付、丢失和生成 ZLRAW
  字节与连续运行相同；CRC/结构复读通过。另验证零延迟 EOF 的未完成窗与长期流式状态。
- `tools/audit_digital_checkpoints.py` 将繁忙组合状态写文件，在新 Python 进程继续输入，
  核对完整记录与真实 ZLRAW 字节；属于假设时钟、速率和刺激的数字功能证据。

现有主 CLI/工作台尚未切换到该运行器，外部写盘位置/幂等恢复、控制与复位、模拟链状态
仍需组合验证。ZLRAW 的跨时期续块与当前密度重建的安全接入也未验收；原重建不会因
这里的字节一致测试就自动获得该能力。此功能不证明硬件吞吐、引脚时序或高密度物理能力。
