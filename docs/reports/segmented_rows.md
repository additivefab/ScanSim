# 分段采集与跨时期像素来源核验

2026-11-13，S4-T05/S4-T09；研究级软件链路，非实机性能验收。

原实现仅把 LINE_START 包视为一行，行中切换 epoch 后的续包及续包质量事件被漏掉。
现在按行起点和原样本计数放置所有续段，保留缺口，不压缩后续列。缺少行起点、计数复位
或钟域改变的包保留原始身份但不猜空间坐标。密度保持缺失/无效原因。

谱系 v2 保存每段来源、列偏移和未定位原因；旧 v1 继续读取和输出。API 与离线报告均按
原映射返回样本索引、epoch、时刻和权重。跨时期摘要标明混合；计数倒退或钟域不唯一时
关闭统一时间轴。仍先逐码线性化、再合并；原码摘要不用于反演密度。

同一标定须显式覆盖完整 capture 时期范围及绑定，窄时期标定拒绝且不创建输出。
不同增益/工作点的逐时期多标定选择尚未实现。测试驱动分别在 epoch 0/1 生成观测参考，
经实际 calibrate 命令拟合；仅当两套拟合项完全相同，生成明确绑定两时期的合成共同参考。
这不是自动放宽任意标定适用范围。合成留出样本最大误差 0.00010211787113267867 OD，
预设软件判据 0.002 OD，不能解释为真实扫描仪精度或随机物理模型收敛。

`tools/audit_segmented_rows.py` 使用实际数字生产器产生两个各 12 样本的行包，随后运行
calibrate/reconstruct/report 和 28 次真实 HTTP 请求；独立进程逐字节回读响应。
缺口与孤包由明确的合成裁剪构造，不是物理链路故障试验。无锚点重建退出 1，同时保留全无效
诊断图；窄时期标定退出 1 且无输出。无效像素的几何候选可能包含浮点舍入造成的极小邻域权重，
候选没有有效归一化权重，不代表缺样被恢复。测试不读取模拟内部真值。

复跑：

```sh
.venv/bin/python tools/audit_segmented_rows.py --out /absolute/new/output
.venv/bin/python tools/audit_segmented_rows.py --out /absolute/new/output --verify
```
