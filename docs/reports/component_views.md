# 同游标二维光路与信号链

2026-11-13，S3-T17，D068。全部内部组件 SIMULATED / ORACLE_ONLY。

新增 `GET /runs/{id}/components?step=115`。从原检查点及原控制历史重放至该模型细步，
只读复制原计算中的源功率/激光门、x/y、面号、几何扫描有效窗与当前场景尺寸，
并返回光斑有效透射率、PMT 入射功率/电流、ADC 输入模型电压。未重新生成随机量或
在前端另算几何；新探针关闭时不分配场景尺寸向量。原码流和物理检查点保持一致。
新源/扫描探针也作为按需波形信号注册，持久 trace 策略仍为原五种探针。

ADC 是最近真实源边沿的零阶保持，不是游标时刻的新采样；响应同时保留源序号、
源时期、采样时刻和 held 标志。例：生效细步 113 的控制后，细步 115 当前时期为 1，
ADC 仍保留细步 112 的时期 0 样本。不能用当前时期替代该源时期。
关光阶段原模型没有求透射率，组件返回未计算/空值，不展示内部占位的 1。
对数板、主放、载板实际输入和实际光程仍为空；v_adc 只叫 ADC 输入模型。
仪器视图不运行组件物理重放，缺根明确未记录，重放超过 100 万细步明确未计算。

页面提供同游标光路功能连接、场景坐标图和信号/数字节点。坐标视野自动覆盖场景与
实际光点，片外 x 不夹紧到片边。面号来自原模型，镜面姿态未建模；示意连线不表示
真实传播距离、光线追迹或电气网表。数字节点保留实际采集窗、在途/未来预生成的区别
及各队列的原占用/容量/溢出。节点点击打开原数据详情或选中对应的已注册波形。
未计算的节点只显示详情，不把占位值重新加入数值波形。

组件请求使用独立游标世代；移动游标、研究/仪器切换与切换运行先清空旧位置和节点。
落在模型细步之间的精确 ps 游标不查询近邻物理组件，数字节点仍按该 ps 查询。
缺少任何一侧的数据都明确显示空/未取得。前端没有推进物理状态的独立动画时钟。

检查包含观察无扰动、原控制重放与跨时期 ADC 保持、关光语义、默认演示/录制 API、
仪器隔离和原件不变。Node 执行实际 SVG/节点函数并核对片外位置、门、点击探针和
旧值清除；这些是函数/结构检查，尚未做浏览器视觉、交互或实机验收。
