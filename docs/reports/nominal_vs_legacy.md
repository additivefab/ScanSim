# nominal 与冻结旧包的对照

本轮在单通道研究预设上实跑标定扫描、标定、样片扫描、密度重建与评价。标定来源为 SIMULATED。
配置采用 1 MS/s 和 2 mm 研究网格，样片为 40 列 × 12 行。重建仅使用可观测码流、标定文件和声明的均匀网格。

## nominal 实跑

- 全图有效覆盖 97.5%。固定的内区掩膜共 288 像素，全部有效。
- 未模糊参考 RMSE 为 0.04343 OD。光斑积分并在像素中心采样的参考 RMSE 为 0.02770 OD。
- 与同一传输码流隔离后重复重建，改写私有真值记录不改变结果。改变靶标密度 0.3 OD 并重新采集，重建中位数变化落在 ±0.015 OD 容差内。

## 冻结旧包

| 算例 | ADC 码比对 | 密度 RMSE |
|---|---|---|
| 包 A 确定性理想整图 | 65,536 个码逐位一致 | V5 为 5.97122151272952e-05 OD，冻结旧包独立重跑为 5.9712215134967987e-05 OD |
| 包 B 确定性理想整图 | 1,024 个码逐位一致 | V5 与冻结交付均为 2.0255271769153482e-05 OD |

旧包理想回归以各自靶标、采样位置及模型已知参考完成。nominal 的标定来自带噪参考扫描，评价网格与靶标也不同。这些 RMSE 仅用于各自算例。
包 A 旧码流用 round 标记行窗，重建使用半拍像素中心。兼容评价分别保留这两个口径。

## 误差分解

噪声、光斑和前端带宽的 2³ 因子实验均已跑通。八组各自从观测参考扫描标定，使用相同的 288 个有效像素评价。

| 因素或交互 | 未模糊参考 MSE 分量（OD²） |
|---|---:|
| baseline | 0.003568685 |
| noise | 6.1347357e-07 |
| spot | 0.00066105062 |
| bandwidth | 1.0071945e-05 |
| noise+spot | 6.0691217e-07 |
| noise+bandwidth | 2.1322901e-07 |
| spot+bandwidth | 1.4586729e-05 |
| noise+spot+bandwidth | -1.6510643e-06 |

基线仍含像素支持与有限采样误差。交互分量由低阶项相减得到，可以为负。输入及案例级数值见 [因子实验记录](stage4_factorial_data.json)。

## 包 B 独立边沿配准

额外扫描已知位置的垂直边，估计配准量。带噪与无噪图在同一掩膜、同一配准量和旧包标定约定下比较。平移在透射率域插值。
借助靶标真值寻找最优平移只作评价上界。这里测的是整体配准补偿，包含光学与采样效应。
