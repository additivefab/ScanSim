# 同步计数与观测时基辨识（S6-T03 部分）

2026-11-13。`zlscan ident --timing-fit config.json --out result`，与其它 ident 源互斥。
配置 `zlscan.timing-fit-config/1` 列出观测附件 SHA256、fit/validation、每采集已知正时间戳
标准不确定度、独立高斯假设、置信水平、秩阈值与可选验证容差。面数是显式协议输入，
不是从波形自动得到的真实机械结构。

附件 `zlscan.sync-observations/1` 需要采集身份、设备/测点/设置及提取说明、原始来源路径
和摘要、明确的绝对同步计数能力，以及 line_sync 的 OBSERVABLE SENSOR 事件。
每条 line_index 必须等于能力声明的事件计数；会话、时期、钟域、来源及能力匹配。
这是已标注同步记录的接口：原始来源仅按块校验 SHA256，不解析仪器私有文件、不自动检测
模拟阈值、不验证上游标注提取规则，也不把自由文本设置声明当作已完成的仪器校准。
真实波形的完整元数据与采样门禁继续由既有 scope 导入器负责。

重复/倒退计数或时间、ORACLE/INFERRED、来源复用、身份混用、矛盾参考明确拒绝。
缺失边沿由已有绝对计数差识别，保留缺号而不压缩坐标、不造边沿、不靠时间间隔补号。
换时期或钟域须另列采集，跨采集不声明同步。64 MiB/每采集十万、总二十万边沿限制；
原始来源可大于附件上限，流式校验。先用 Python 整数做绝对时间/计数差，再转浮点；
跨度超过 2^53 ps 或 2^53 个计数拒绝拟合，原始身份仍以十进制字符串保存。

全局候选是每采集独立截距+共同线性行周期，不能自动解释所有周期调制。
逐面候选是每采集截距+各面间隔数×各面周期。面号只有同刻的可观测 reference/index
锚点才能给出，随后使用已观测绝对计数展开；不凭“相似周期”猜面号。
没有参考的拟合采集从逐面模型显式排除，保留全局候选；缺面参考不输出唯一逐面数值。
只有整转采样时，各面周期不可分，但被支持的整转周期和可报告。输出秩、零空间、
可辨识组合、逐参区间与协方差/相关性，未辨识参数为 null，不把最小范数诊断当真值。
负的已辨识周期不夹紧，模型不报告为完全辨识。

直接对时间戳拟合，每采集消去 nuisance 截距；不是对相邻差分做独立样本回归。
条件协方差按已声明的原时间戳 sigma 构造，不用残差缩放；自由度扣除截距和周期秩。
模型同时报条件卡方诊断，未指定拟合优度门槛时不声称模型已代表真实机器。
共同参考、计数/相位误标、时基校准偏差、慢漂移、仪器系统误差不在这些条件区间中。
原事件 uncertainty_ticks 不擅自当作 Gaussian sigma。

每个真实交付间隔保留原始计数差/时间差、跨度平均周期/行频与条件不确定度。
跨缺号区间只报跨度平均值，不称瞬时行频。单行间隔的描述均值/标准差仍包含测时噪声与
共享端点相关性，不能直接解释为物理转速抖动，也不能由本接口分离真实机械/仪器噪声。

validation 不调周期/相位或拟合截距，仅以首个已观测时间作初始锚点，首点不评分，
后续累积时间残差参与显式容差比较。误差名义不确定度包括首点与当前时间戳以及独立拟合
参数的协方差；留出残差之间仍共享初始锚点/参数，不能把每一点当独立检验。
无验证为 not_executed，无容差为 not_assessed，预测不可辨识为 unidentifiable，
不满足容差为 mismatch。SHA/原源/采集身份复用拒绝，不因文件不同就声称统计独立。

固定种子 20261113 的合成源使用约 2^60 ps 的原时间、三面 1000000/1100000/900000 ps，
加 20 ps Gaussian 输入噪声再取整到 ps；声明模型为条件近似，未验证统计区间覆盖率。
六个实际 CLI 案例覆盖正常、缺号、无相位、仅整转、留出失配、来源复用。
正常逐面最大误差 1.4250000002793968 ps，小于预设 100 ps 软件判据；
留出最大累积误差 65.3902527242899 ps，小于合成协议 200 ps 判据。
数值仅为合成算术验证，不是实际转镜/ADC/仪器指标。
