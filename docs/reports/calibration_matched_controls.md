# 匹配控制：对数下限、加性暗与参考拟合

2026-11-13，S4-T02，D050。上轮低光独立验证出现密度偏差与大量无效点，本轮固定输入响应、
对数后极点、ADC、曝光窗口及拟合方法，只交叉改变散粒噪声开关和假设暗电流。
不把全部残差归于数值网格，也不使用前向真参数替换观察标定。

## 假设与数据

沿用 `low_light_calibration_grid.md` 的 os=32、ADC 1 MHz、前响应 20 kHz、后响应 30/50 kHz、
白场初级电子率 1e8/s。暗电流取 0 或白场平均阳极电流的 1e-3（约 16.02 pA）；
倍增因子 F=1，ADC −1..2.5 V、16 bit。所有参数均为 ASSUMED，不写入硬件画像。

四案例：无噪声/零暗、无噪声/加性暗、有噪声/零暗、有噪声/加性暗。
确定性案例各一次，有噪声各八次。每次参考和验证用独立 seed，各案例间也不复用。
参考为暗、白和 D=0/1/2/3/4；独立验证为 D=0.5/1.5/2.5/3.5。
每次曝光有 512 个 ADC 样本的明确预热，参考 16 行、每阶 64 列，暗/白/验证各 320 列。
模拟历史在各稳定曝光间连续，只有测量窗口入 raw，预热缺口保留实际源序号。

共 36 个原始文件、18 个候选拟合、72 个独立密度实例。只从重读的原始参考和已知参考密度拟合；
验证标签在重建后计算残差。列是定点光度研究的分析 bin，不代表完整空间扫描或积分筒位置响应。

## 发现对应的软件修复

现有拟合为 code = a + b log10(T+d)，而零暗时前向 AFE 会用 max(I,I_floor)。
数值下限不是加性暗电流；优化器收敛不代表这个拟合族能再现所有参考。
新拟合保存各参考的 T、观测/拟合码和逐点残差。
协议可声明有限非负 `transfer_reference_tolerance_code`；逐点误差在范围内为 compatible，
否则 mismatch。未声明则 not_assessed，不能当作通过。

确定性控制显式声明 1 码参考再现容差，包含本研究的 ADC 量化；它不是实测不确定度。
有噪声案例没有给定适当的参考不确定度，因此保持未评估，不套用 1 码去判定合格。
诊断候选的独立残差在参考验收前记录；应用明确容差后的失败工件不再送重建计算。
失败标定可保存检查，但 CLI 返回非零，重建拒绝该通道；没有删除坏点、改成 MODEL 或清掉失败标记。

校验放在合同层，标定与重建仍独立；全量测试先发现了一次 recon→calib 实现依赖，
已移除并用导入边界回归验证。拟合生成器升级 v2，避免新旧诊断工件沿用相同 ID；
旧文件兼容，默认前向模型与拟合公式不变。未评估的历史/新文件也不因此获得实机准确度证书。

## 执行与解释

```bash
.venv/bin/python tools/audit_calibration_controls.py --out NEW_DIRECTORY
.venv/bin/python tools/audit_calibration_controls.py --verify NEW_DIRECTORY
```

输出独占创建；verify 在新进程重读原始数据、重拟合、重建并核对候选/评估标定文件。
加性暗控制只用于匹配拟合假设，不是提高硬件暗电流的建议。
条件差异不等于误差源占比，不能用 RMSE 相减分解贡献。即使确定性拟合改善，
低光噪声、下限、对数后滤波和扣暗仍可能限制随机案例；实测传递与动态辨识仍缺。
最新全量 1152 通过、2 项 RTL 因 Icarus 不可用跳过（79.87 s）；Ruff/格式通过。
