# 持久研究探针与统一恢复游标

2026-11-13，S3-T13/S3-T14 的持久波形记录部分。SIMULATED / ORACLE_ONLY，
不是实际仪器波形、标定输入或扫描性能证明。

在已有 `zlscan.physical-recording/1` 配置增加可选字段：

```json
"trace": {"probes": ["power_w", "v_adc"], "base": 64, "factor": 8, "keep_raw": false}
```

不指定 trace 默认不记录高频探针。支持 x_m、t_eff、power_w、current_a、v_adc，
每个物理通道记录相同选择。base/factor 是显示摘要配置，不是硬件参数。
keep_raw 需显式开启，原始探针为 float64；否则仅保存多层极值/首末/计数。
所有数据只读取同次 Chain 输出，不另跑模型，不触碰随机数或前端状态。

每次有界生产块封存一个 HDF5 文件到 probes，以固定序号命名；文件独占创建、
关闭后不再修改。index.jsonl 追加记录源细步范围、序号和整文件 SHA256。
每层未满桶是固定数量的 min/max/first/last/count 与整数起点，随统一物理根保存；
不把未满桶当完整桶落盘。恢复后继续合并，因此摘要不随生产分块或恢复边界改变。
HDF5 保存已完成的各层桶；查询将已存桶及根中的未满尾桶有界合并。
摘要包含真实支撑范围与 boundary_extra，窗口边缘外的极值不冒充窗口内事件。
粗视图至多 pixel_width 桶；已存原始细窗最多 2×pixel_width 点。

开启探针时使用统一物理检查点 v2，确保旧读取器拒绝而非忽略探针继续写入。
不启用时保留 v1 和旧默认行为。根先配对 raw/journal/probe 索引的 fsync 前缀，
HDF5 内容和目录项落盘，再发布一个统一根；没有独立“探针最新根”争夺权威。
恢复核对配置/模型/物理控制及数字状态，另核对探针根、步号、通道、每层未满桶
边界、索引前缀与各 HDF5 摘要。原位恢复拒绝未知索引尾部或孤立块，保留原件。
显式新目录分支只复制已提交前缀与对应块，不复制故障尾部。
写入失败后不允许发布已推进模型的新根；从原已提交根恢复，不回写或截断旧目录。
这是软件 fsync/根协议，不是物理掉电签核。

`serve --run` 研究视图优先读取已存探针，标 recorded 与精确/摘要状态；
原始未保存且当前缩放比摘要更细时，从真实历史点重放并标 replayed，不能说是记录。
未选探针同样只能明确研究重放；仪器视图不能取得这些内部信号。
CLI replay 仍是独立模型重放，不因存在探针文件而变成实际观测。

生产载荷最多一百万细步，跨参数生效点继续分段；保留固定 64 层未满桶。
原始/摘要磁盘随历史增长，索引查询顺序扫描，不将全部记录装入内存。
文件/目录数随生产块增长，小块会有明显 HDF5 元数据成本；未以短算例宣称大幅面
性能/冷缓存定位/FPS 达标，也不称全系统元数据内存恒定。

回归覆盖尖峰、尾桶、跨块边缘、原始/摘要输出预算、篡改/重签不合法游标拒绝、
跨块摘要相同、续写后逐字节 ADC 和物理末态一致、故障后旧根保留、分支原件不变、
双通道控制/reset 连续性及公共 CLI/工作台直接查询/细窗重放。
