# 多工作点标定集合与逐时期重建（S4-T01）

2026-11-13。新增自包含 `zlscan.calibration-set/1`、捕获描述 v2 的逐时期完整绑定，
以及保存逐段坐标/标定身份的图像谱系 v3。原单标定入口与 v1 捕获序列化保留。
公开 `calibration-set` 命令组合已有标定，禁止改绑定、自动延长时期、嵌套集合、
重复标识、MODEL 或覆盖已有输出文件。集合可直接交给现有 reconstruct 命令。

每个实际观测时期须恰好有一份适用标定。会话头仍约束硬件/接线/固件/寄存器，
逐时期 hash/增益用自身完整声明；未知信息不从模型补齐。缺失或歧义在输出前拒绝。
每段先按自己的传递与暗白参考转成透射率，再使用自己的延迟/几何/面增益沉积。
磁盘暂存按输出行累积，支持不同 y 偏移，不保留整幅常驻像素数组。

同一行换时期后借用行首逐面相位是实际缺陷，已同时修正新、旧路径。
没有该时期可观测锚点时标 FACET_UNRESOLVED；各时期的新行具备自身锚点时，
各自几何/y偏移/面增益可正常应用。无头输入缺少时期身份，不能套用集合。
质量事件按原时期/源样本匹配，缺口及未定位段保留，像素谱系返回逐样本标定ID。
离线报告的实际 JS 帮助函数也使用逐段坐标；该检查不是浏览器验收。
图像服务可按完整捕获描述核对每个工作点，任一增益不符隐藏密度并标不匹配。
