# 阶段 3 小幅面实测（100 × 1000）

机器为 macOS-15.7.6-x86_64-i386-64bit-Mach-O，使用 Python 3.14.7。研究模式使用 demo 预设衍生场景，共
100 列 × 1000 行（每像素 2 mm，1 MS/s，每样本 4 细步），参数来自仿真假设。

- 细步数 1e+07，ADC 样本数 2.5e+06。
- 端到端（链 + 链路 + 采集 + 队列 + 原始文件 + 完整性 + 重建）：196.5 秒，
  5.09e+04 细步/秒，Python 内存峰值 700.6 MB；
  完整性 complete，重建状态 complete，丢块 0。
- 流式写盘：130.9 秒，Python 内存峰值
  4.0 MB，写出 1000 行。
- 两路输出的块元数据和全部 1,592,000 个 ADC 码一致，ZLRAW 文件 SHA-256 也相同。

本算例未设耗时阈值。4000 × 5000、7000 × 8600、双通道以及 RTL 协同未执行。

模拟场景的横向网格为 100 像素，最简重建每行输出 1,592 个原始采样码，未生成标定后的密度图。
内存数字来自 `tracemalloc`。流式统计从同步计划建立后开始。流式路径直接写原始文件，端到端路径还运行链路、队列、完整性检查和最简重建。

本轮修复前的本地算例虽有同样的块标签，后续行共有 1,590,408 个码与批处理不同。保留该原始产物供复查。
