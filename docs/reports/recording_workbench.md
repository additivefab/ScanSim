# 冻结录制工作台（S3-T16，部分）

2026-11-13。保存的研究录制软件验证，不是实机性能或浏览器视觉验收。

```sh
zlscan serve --run recording_run --port 8765
```

自动识别公共 recording CLI 的定义和统一根；每个物理通道注册为
recording-c0 / recording-c1。只读固定最后一次提交，不跟随生产者。
注册只验证并加载原状态，不推进模型、不打开追加写入器；查询不改源文件。
定义、场景、提交根、原码流 CRC/结构及 raw/journal 提交摘要均核对。
未知尾部不参与查询，源提交前缀改变则拒绝；不以 run.json 判断进程存活。

仪器视图只显示实际交付的 ADC。未保留/未交付位置为 null，missing_count
不全部等于丢包。保留逐点 epoch；粗桶仅供显示，跨时期标 mixed_epoch，
不把混合桶当一个时期或反演成密度。ADC 细窗至多 2×pixel_width 点，
粗窗至多 pixel_width 桶，含 min/max/first/last/count 与有效计数。
临时 SQLite 索引位于源目录之外，逐块建索引并分块读取载荷，服务查询线程
结束后清理。索引磁盘随块数增长；注册及每次前缀复核需线性读取，
不是已达 150 ms 的大幅面交互证明。元数据历史/配置内存也仍有软件限额。

研究视图的 trace/state/replay 使用真实历史根和原参数生效时刻，只计算请求窗口，
标 ORACLE_ONLY / REPLAYED；缺历史标未记录，损坏历史拒绝。
单窗口最多 1,000,000 模型细步，超额需缩放；不会把部分重放冒充整窗。
仪器视图不执行源模型重放。控制、模拟传输损失只出现在研究视图。
未持久保存的模拟事件仍标未记录，即使附带部分已知事件；事件超 4096 截断显式标记。

ADC 波形点击可查询实际交付样本的序号/时期/行号/码，以及原 journal 中白名单
可观测向量：capture_time、capture_count、selection_time、window_count、
overflow、overflow_valid。压缩向量按包有界解码，不将整个诊断日志升级为可观测。
时刻/计数以精确字符串传输；超大包返回未计算。sample_time 来自已存时钟定义，
捕获时间来自原可观测记录；未登记的引脚、输出和主机时刻为空。
研究视图另外列出原 LinkConfig 方程推导的 MODEL_ESTIMATE，及原日志末级队列完成
诊断；二者均 ORACLE_ONLY，不能充当主机收件或实测时序。
后台源索引保留 uint64 精度；浏览器整体细步轴超过 2^53−1 时明确禁用定位，
不把舍入坐标当可用范围。页面提示冻结提交、来源、研究重放及缺记录原因。

验证包括真实 CLI/HTTP 双通道记录、实际码/缺口/时期与源文件核对，控制感知
模型重放与历史引擎核对、原件摘要不变、新进程全部响应一致。
`tools/audit_recording_workbench.py --out DIR` 生成输入并查询，
`--verify DIR` 新进程复读。单测另覆盖未知尾部、前缀篡改、旧缺失历史、
丢包、自定义链路、64 位源索引、压缩输出边界与关闭清理。
Node 只验证页面脚本语法/提示/请求竞态；未执行浏览器视觉验收。
全量、正式提交/安装包和证据结果在 PROGRESS 与配套 record 更新。

该入口没有补齐持久探针迹线游标、实时跟随、跨时期密度重建、完整光路/逻辑联动、
FPS/P95、实机或其它阶段门槛。calib/recon 真值隔离不变，噪声高密度能力仍未证明。
