# 精确数字时刻与统一游标

2026-11-13，S3-T14/S3-T17，D067。SIMULATED / ORACLE_ONLY。

recording 的原数字输入历史现在支持 `GET /runs/{id}/digital-state?tick=25000001`。
tick 是有符号 64 位范围内的规范十进制整数 ps，必须位于已提交模型源时间域的
左闭右开范围。数字状态包含该 ps 的事件。instrument 返回未记录，不运行内部模型。
旧 v1–v3 没有原数字输入时不反猜状态；未知/损坏的输入拒绝，重算超过 100 万细步
明确未计算。完整原操作逐数字状态摘要验证，切在原批次中间时先重算整个原物理区间、
验证源组的码摘要/时期，再仅把数字链关闭到目标 ps。原根/原配置/原输入始终只读。

原生产者以批次提交源码，一组包含的未来源码可能已预生成。因此：

- source.sampled_rows 是目标时刻确实已发生的源采样数量，按原时钟计算。
- link.in_flight_rows 只计已采样、尚未到捕获边沿的行。
- link.prefetched_future_rows 是原批次里预生成但尚未到采样边沿的行，单独显示。
- declared_next_index 是声明批次的边界，不能当作当前时钟计数。
- 捕获计数、当前采集窗口和各级队列占用来自重放状态；不返回全部内部码数组。

EOF 会在生产接口中一次排空。当前没有把该完全排空状态倒推到源时间域之外，
尚不支持单独浏览 EOF 后的排空时间轴。这里的队列能力、时序和延迟沿用原配置的假设，
不能升级成实机读数或硬件性能证明。

页面提供整数 ps 输入、波形游标叠加、事件按钮和 ADC 源边沿选择。原生模型质量事件
保留 time_ticks，传输丢失使用日志原 time_ps，控制事件按原细步时钟换算。
当游标处于模型细步之间，数字状态照常查询，物理瞬时探针明确未计算。
所有 state、digital-state、样本详情绑定独立的游标世代；即使新选择没有发起同路由请求，
旧选择的迟到响应也不能写回。窗口迹线不因仅移动游标而失效。事件按钮使用 textContent。

测试对照逐时推进的独立数字管线，覆盖跨时期、捕获/完成边沿、上升/下降沿、负偏移
溢出前视、队列溢出和背压；另外测试整数时刻、预算、码摘要失配及仪器隔离。
Node 运行实际页面函数，检查大于 2^53 的时刻、非整数采样周期、原生事件与 ADC 选择、
迟到响应和整段脚本语法。实际 HTTP/新进程工具为 `tools/audit_digital_cursor.py`。
这些是软件函数与 HTTP 证据；浏览器视觉/交互、W01–W11 整体验收和实机仍未执行。

开发复读曾发现 events 的嵌套质量网格元数据在不同进程中键插入顺序不同；解析后的
JSON 完全相等，但 HTTP 字节不同。保留失败响应，并增加红灯回归后统一 HTTP JSON
递归按键名序列化。数组的事件顺序仍由原事件语义决定，没有改写事件时间或数值。
正式工具记录完整响应原文/摘要以及新进程复读原文，不能只用解析结果相等代替字节相等。
工具另存每请求实际 HTTP 计时和原检查点尺寸；该输入仅 787 细步/双通道，缓存未控制，
没有浏览器绘制，不作为大幅面、150 ms 或 30 FPS 验收。
