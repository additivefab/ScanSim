# 迹线存储基准（S0-T10）

脚本：`tools/trace_store_benchmark.py`（可重跑）；数据：`trace_store_benchmark_data.json`。

机器与版本：macOS-15.7.6-x86_64-i386-64bit-Mach-O（x86_64），Python 3.14.7，h5py 3.16.0，NumPy 2.5.4。

## 测的是什么

4 路合成探针，每路 20,000,000 个 float32 样本，叠加了 50 个三样本宽的脉冲（均值降采样会抹掉它们）。每路存多层极值摘要（`zlscan.trace.pyramid`，层大小 [78125, 9766, 1221, 153]）和前 2,000,000 个样本的原始窗口；其余原始样本不存，按方案 5.14 节从检查点重算。
若全部原始样本都存，4 路共 320 MB。

## 结论的范围

- 只对这里测的规模成立：4 路、每路 2000 万样本、一台机器、合成数据。
- 没有清空操作系统缓存（需要 sudo），所以没有真正的冷盘数据；"重新打开"只含句柄创建的开销。
- 摘要层保住了全部脉冲峰值（脚本里有断言；单元测试另有覆盖）。
- 是否保留 HDF5：见 DECISIONS.md D010。
