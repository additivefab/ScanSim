# AD9268 V4.1 资料与 M02 门槛审计

2026-11-13。资料目录包含模块用户手册、AD9268/AD8132等芯片手册、原理图PDF、尺寸图DXF/PDF和 `AD9268_V2.zip` FPGA例程。所有非DS_Store文件已逐字节计算SHA-256，清单在 `evidence_runs/2026-11-13_ad9268_audit/record.json`。

## 文档支持的事实

用户手册和AD9268数据手册共同支持：双通道、16位、最高125 MSPS；模块输入声明±4.5 V，模拟带宽声明-3 dB 350 MHz；数字接口1.8 V，可选CMOS/LVDS；芯片有SPI控制接口和时钟分频/测试模式相关寄存器。用户手册还描述5 V模块供电、SMA模拟输入和2×23数字接口。例程压缩包包含Cyclone IV工程、PLL、SPI RTL和约束文件。

这些是手册/文件事实，不是当前板卡的实测事实。文档没有提供本次设备的寄存器读回、采样时钟实测、测试码捕获、通道角色确认或板级导通证明。例程RTL也不等于已连接板卡的运行回执。

## M02 当前结论

M02 仍未完成。可将上述值作为带来源的文档参数进入硬件画像，但硬件身份、真实运行方式、寄存器状态和通道映射必须保持未知；不得把125 MSPS、1.8 V接口或例程工程写成当前设备的实测配置。阶段6实测门槛和阶段3/4整体验收不因资料结构审计关闭。

下一批可直接解锁M02的证据是：板卡序列/版本照片或可验证身份、SPI寄存器dump、明确采样/数据时钟与触发定义、两个通道测试码原始捕获（带文件摘要/会话/时期）、以及板卡与FPGA接口导通/逻辑映射记录。
