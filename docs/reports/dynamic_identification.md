# 观测单指数动态辨识（S6-T03 部分）

2026-11-13。新增 `zlscan ident --dynamic-fit config.json --out result`。
该配置列出每条采集的 CSV、元数据、原文件 SHA256、单通道、阶跃时间/窗口、方向和分区。
格式为 `zlscan.dynamic-fit-config/1`；与原 CSV/码流/表导入互斥，不代填设备条件。

候选模型是观测端到端响应：`y=b+a*(1-exp(-max(t-t0,0)/tau))`。
上升和下降分别拟合一个正 tau；每条 fit 采集有独立的基线与有符号幅度。
这不是物理链新模块，不把组合时间常数拆成 PMT、前端或仪器参数。
AC、未补偿探针、缺少元数据、采样声明不一致、不明来源或范围外窗口拒绝辨识。
导入器仍可查看不完整数据。多路记录不被自动解释为同步。

显式选择 tau 搜索区间、置信水平、秩阈值及假设来源。只支持声明的独立高斯、已知正输出
标准不确定度，并以给定阶跃时刻和导出时间为条件。搜索 log(tau)，每次重拟合每条曲线
基线和幅度，报告名义一参数 profile likelihood 区间（卡方近似阈值）。
该数值搜索与单一连接区间不是对任意失配/多峰数据的全局数学保证。
区间任一侧不能在声明范围内闭合、局部设计秩亏或幅度方向错误，tau 输出 null。
不把搜索边界点或最小范数代表当唯一参数。未辨识时拟合曲线只供诊断。

另报物理单位的局部条件协方差、相关性、自由度及条件卡方 p 值；不从残差反推/缩放
已声明的 sigma。区间不包含输入、阶跃时刻、时间基准、仪器传递函数、共享参考误差或模型
失配；不能把条件区间当硬件误差预算。没有指定的拟合优度阈值，不自动声明模型正确。

validation 从未参与 tau、基线/幅度、区间或搜索范围选择。验证水平必须来自配置中独立
声明及来源，而不是从留出输出拟合。来源 SHA256 或设备/会话/时期/采集 ID 复用即拒绝。
分区不同或文件不同仍不能证明统计独立，`independence_established=false`。
没有验证记 not_executed，没有容差记 not_assessed；显式容差不满足记 mismatch 并退出 1。
JSON 保留全部逐点观测、预测、名义残差和来源摘要；SVG/PNG 分开画上升/下降与拟合/验证，
各采集散点不连线，图上说明没有同步，也不对齐或重采样原记录。

本轮固定种子 20261113，8 份独立声明的解析阶跃+0.001 V 高斯噪声合成 CSV，真实 tau
为 2 ms / 5 ms；拟合数据四份，验证四份。实际公共 CLI 估计
2.0006388467242297 ms / 4.997382342722833 ms，相对误差

另跑验证失配、平坦波形、来源复用三个失败案例；改变验证水平不改变拟合参数与区间。
这些数据不代表真实光电链、真实仪器或便携机性能，也不是区间覆盖率的蒙特卡洛验证。
