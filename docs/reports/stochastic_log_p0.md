## 明确关闭的研究响应

仅当显式设置 `DetectorConfig.pole_hz` 时，在对数之前启用一阶电流节点：

```text
tau = 1/(2π fc)
I_bin[k] = Q[k]/dt
a = exp(-dt/tau)
y[k] = a y[k-1] + (1-a) I_bin[k]
V_log[k] = V0 + polarity * slope * log10(max(y[k], I_floor)/I_ref)
```

电荷格在一格内作为恒定平均电流，采用精确 ZOH 更新；旧前端的分段线性低通仍按原合同推进。
状态从零开始，预热必须显式安排；状态跨块、跨行连续并写入检查点。模型版本更新为 `chain-0.2`，
旧检查点拒绝复用。该参数是 ASSUMED 研究输入，本机响应参数仍为未知，未自动填入任何硬件画像。
该候选不等同于单电子脉冲、PMT 渡越时间或真实输入电路的完整模型。

对恒定电子率 λ、平均电荷 q=eG 和倍增因子 F，有独立解析矩：

```text
E[y] = λ q
Var[y] = F λ q² tanh(dt/(2tau))/dt
dt→0: Var[y] → F λ q²/(2tau)
```

运行清单同时报告 dt/tau 和有限格宽/连续极限的电流方差比。仅配置一个极点不等于分辨率足够；
例如 1 MSPS、os=4、8 MHz 极点只有约 0.159 的方差比，仍明显欠分辨，不能据此宣称已经消除网格误差。
