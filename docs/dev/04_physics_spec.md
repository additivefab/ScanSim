# 04 物理与数值规格

每节给出：方程、离散化、旧包里的对应位置、要用测试固定的性质。旧包位置写作 `A:行号`（`legacy/package_a/src/scanner_sim.py`）或 `B:行号`（`legacy/package_b/src/scanner.py`）。

内部一律用国际单位制。常数：`h = 6.62607015e-34`，`c = 299792458`，`e = 1.602176634e-19`。

本文件中的数值例子都是旧包的教学假设，不是设备参数。

## 1. 底片：密度与透射率

```text
T(x, y) = 10^(-D(x, y))
```

- 输入是密度图或透射率图，带物理尺寸。8 位普通图片不是定量输入，读入时告警。
- 之后所有光学计算在 T 或光功率上做。
- 片外区域默认 T = 1（透明直通，B:206）；可配置为片夹遮挡。
- 超采样：按条带即时生成，倍数可配（包 A 用 4，A:71）。

固定性质：常数 T 经任何光斑卷积后不变；对密度做卷积与对透射率做卷积结果不同（A 的 `test_transmission_not_density_blur`）。

## 2. 扫描几何

```text
行频        f_line = N_facet · rpm / 60
转镜角速度  ω = 2π · rpm / 60
反射光偏转  φ = 2θ + φ0              （反射镜：光学角是机械角的两倍）
理想平场    x = f · φ                 （f-theta）
普通透镜    x = f · tan(φ)            （不可与上式混用）
扫描速度    v_x = 2 f ω
像素率      v_x / p_x
采样率      f_adc = M · v_x / p_x     （M 为每像素样本数）
送片速度    v_y = p_y · f_line        （连续送片）
```

这些量互相约束，配置层只允许指定其中一组自变量。旧包示例：6 面、10000 rpm、50 µm、500 m/s 反推等效焦距 238.732 mm（A:63）。

实际映射 `x(t, facet)` 的实现分级：

| 级别 | 形式 |
|---|---|
| L0 | 理想 f-theta，x 与时间成正比 |
| L1 | 多项式或正弦畸变（A:163 三次；B:169 正弦）+ 逐面偏移 + 逐面塔差 + 转速波动 |
| L2 | 实测查找表 |

连续送片时行内 y 随时间变化：`y(t) = y_line + v_y · (t - t_mid)`（A:166，B:203）。

行同步：真值侧产生一个物理时刻；数字侧用 ADC 时钟域的同步器采到它，量化误差由此产生。两者不相干，每行的采样相位不同。旧包都没有这一点（每行从同一相位开始），这是要新做的。

## 3. 光斑、眩光、集光

```text
T_eff(x_s, y_s) = ∬ h(u, v) · T(x_s - u, y_s - v) du dv,   ∬ h = 1
P_det(t) = P0(t) · η_pre · η_collect(x_s) · T_eff + P_stray
```

- 核心光斑 L1：椭圆高斯，`σ = FWHM / 2.354820045`，随场点可变。
- 眩光：一个或多个宽尾分量，在降采样网格上卷积后叠加；总权重归一。
- 边界：片外按第 1 节的规则取值，不用"最近邻延拓"代替物理边界。
- `η_collect(x)`：位置相关的收集效率表。旧包用抛物线（A:194，B:207）。
- 杂散光：与信号无关的常数项（A:196）与眩光分开建模。

### S5-T03 软件规格（2026-11-13，默认关闭）

`PsfConfig` 的核心椭圆高斯保持原有字段；可选宽尾混合由
`glare_weight ∈ [0,1]`、`glare_fwhm_x_m > 0`、`glare_fwhm_y_m > 0` 指定。
`T_eff=(1-w)·G_core[T]+w·G_tail[T]`，两个分量都在透射率域用同一固定 Gauss–Hermite
降采样规则计算，权重分别归一后再混合。`w=0` 时执行旧核心路径，默认结果保持不变；
常数透射率必须逐位保持。它是一个宽尾候选，不代表完整PSF、眩光成像或已测参数。
对应约束资料为 M06 点靶/刀口/网格；M06 未取得前只能运行合成开关影响与守恒测试，
不得把 `glare_weight` 升级为实测或用其解释高密度能力。

## 4. 光子与 PMT

每个时间箱 Δt 内：

```text
E_γ = h c / λ
μ = (P_det · QE / E_γ + R_dark) · Δt          期望初级电子数
n ~ Poisson(μ)
q | n ~ Gamma(shape = n / (F - 1), scale = G · (F - 1))    F > 1
q = n · G                                                    F = 1
I = q · e / Δt
```

其中 `R_dark = I_dark / (e · G)` 是等效的暗事件率，F 是过剩噪声因子，G 是增益。

性质：`E[q] = μ G`，`Var[q] = F μ G²`（B 的 `test_poisson_gain_statistics`；A:203–211，B:126–134）。

规则：

- 低计数时不得用高斯近似代替泊松。
- 改变 Δt 不得改变固定曝光窗内的统计量：对同一物理窗口，细分后各箱计数之和的分布应与不细分时一致（泊松可加，天然满足；Gamma 倍增按形状参数可加，也满足）。写成测试。
- 渡越延迟与带宽极点属于"快时间响应"，是可选层。参数无来源时信号标 `ASSUMED`，界面显示"假设"。
- 限幅只是告警阈值，置标志位，不代表真实的空间电荷模型。
- 增益下垂与恢复：L1 用一阶状态，方程在实现前按 `ModuleSpec` 写出并补充到本节。

## 5. 一阶低通的离散化

所有一阶线性环节统一用"输入在一步内线性变化"的精确递推（A:102–113）：

```text
u = 2π f_c Δt
a = exp(-u)
r = (1 - a) / u
y[k] = a · y[k-1] + (r - a) · x[k-1] + (1 - r) · x[k]
```

不用 `y[k] = a y[k-1] + (1-a) x[k]` 的零阶保持形式（B:120–124），它会带来半步的相位超前，步长收敛慢一个量级以上。

高阶滤波器写成状态空间形式，用同样的"分段线性输入"假设做精确离散化（矩阵指数）。

电流相关的时间常数（非线性）逐点递推，系数随当前电流变化（A:116–129）；这是要用即时编译加速的热点。

固定性质：直流输入下输出恒等于输入；步长减半时结果收敛，收敛阶在测试里记录。

## 6. 模拟前端

**静态**

```text
对数：V = V0 + s · S · log10( max(I, I_floor) / I_ref )      s = ±1 为极性
线性：V = V0 + R_T · I
```

极性是配置项。旧包两种极性都有（A:133 电流越大电压越高；B:104 相反）。

L1 可加对数一致性误差与温漂；L2 用实测查找表。

**动态**：L0 无；L1 固定带宽一阶；L1+ 电流域状态方程（时间常数随瞬时电流变化，上升下降可不对称），实现前按 `ModuleSpec` 写出方程并补充到本节。

**二级主放与驱动映射**

```text
V_adc = g · V_front + b       再经压摆率与输出限幅
```

（B:229 的 `adc_driver_gain`、`adc_driver_offset_V`。）量程要分四处描述：对数板输出、二级主放输出、ADC 模块输入、芯片差分输入。

**耦合**：直流或交流可选。交流耦合是一阶高通，状态跨行保持，用来观察长均匀区的基线下垂。

**抗混叠**：任意极零点。预设包括两级一阶（A:221）和二阶巴特沃斯（B:183）。

**噪声**：电流噪声与电压噪声各自按谱密度配置，在细步上生成后经过后续滤波；不在采样点直接加一个固定方差的高斯量（B:230 的做法在换采样率时不成立）。

## 7. ADC 转换

```text
LSB  = (V_max - V_min) / 2^B
code = clip( floor((V - V_min) / LSB), 0, 2^B - 1 )
V̂    = V_min + (code + 0.5) · LSB
```

（A:140–149，B:113–118。）

- 采样时刻 `t_k = (k + 0.5) / f_adc + jitter`，在细步波形上插值取值。
- 饱和单独置标志，不靠码值是否等于端点来判断。
- 非理想项（增益、失调、非线性表、热噪声）各自可开关。
- 码制（偏移二进制或补码）属于输出链路，不属于转换。

## 8. 输出链路与流水线

- 流水线延迟 L 拍：`code_bus[k + L] = code_sample[k]`。AD9268 手册：CMOS 模式 12 拍；LVDS 双通道为 12 与 12.5 拍。这是芯片手册能力，不是本机配置。
- 标签（行号、像素列、有效标志、行末、帧首）与数据经历相同的 L 拍延迟（A 的 `test_pipeline_alignment`，B 的 `test_adc_tag_alignment`）。
- 输出传播延迟另列一项，不并入整数拍。
- 每个延迟只计一次。

### 对数传递标定

用遮光、无片和已知密度阶梯的原始码拟合 `code = b + s log10(T + d)`。白场光信号定义为 1，`d` 为相对暗量。对阶梯每档使用中央半带的中位数，对参考场使用中位数，并记录逐列标准差、首末行漂移与白参考异常列。拟合给出相对光强查找表及斜率、截距不确定度。查找表的外推策略为无效。

### 阶跃延迟辨识

对整数皮秒时间戳的同向明暗边拟合 `v = v0 + A·(1-exp(-max(t-t0-delay,0)/tau))`，将固定偏移与一阶响应时间分别报告。可观测的同步注入监测沿与被测采集必须属于同一会话和时期。仅有名义靶标位置时报告整体配准偏移，物理延迟仍为不可辨识。

### 逐面几何与相位

行同步间隔与预期行周期比较，超差后停止分配相位，直到取得新的可观测锚点。锁定相位组用刻线位置拟合 `x(u)=a+b*u+c*u³`，同时报告残差。有已知斜率的斜线靶时，用扫描向残差除以靶标斜率得到送片偏移。均匀场只能提供相对增益，送片偏移标为不可辨识。

## 9. 重建

默认参考路径：

```text
code → V̂ → V_front = (V̂ - b̂) / ĝ → Î（查找表或对数逆变换）
     → T̂_sample = (Î - Î_dark) / (Î_white - Î_dark)
     → 像素内按权重合并 T̂_sample → T̂_pixel
     → 二维重采样到规则网格
     → D̂ = -log10(T̂_pixel)，同时生成无效掩膜
```

带帽子的量全部来自标定文件，不来自 `truth` 配置。

- 合并在线性域做。对数码的算术平均对应光强的几何平均，不是同一个量。
- `T̂ ≤ 0` 时置标志位 0，密度写 `NaN`。旧包夹到 1e-8（A:310，B:142）的做法不沿用。
- 二维重采样统一处理行内送片运动、逐面偏移、畸变；声明坐标来源、支持范围、权重、边界规则。
- 当前双线性沉积内核以输出像素中心为原点，逐轴在一倍像素间距内赋正权重。有效权重合计小于 0.5 的像素标记支持不足；参与支持的无效样本按位并入像素掩膜。入口当前使用操作方声明的均匀坐标。
- 延迟补偿量来自标定的估计。

## 10. 预算器公式

```text
几何：见第 2 节
光子：N_e = P_clear · 10^(-D) · QE · t_pixel / E_γ
      σ_D ≈ sqrt(F / N_e) / ln(10)          仅高计数近似，注明适用条件
量化：ΔD = LSB / (|S| · g)                  对数前端，每个码对应的密度步长
数据：原始速率 = f_adc · 通道数 · 每样本字节
      保留速率 = 原始速率 · 保留占空比 / 抽取比      仅适用于原样保留或简单抽取
      线上速率 = 保留速率 + 包头与元数据
突发：积压(t) = max over 历史 [ 累计到达 - 累计服务 ]
```

采集模式决定判定方式：

| 模式 | 判定 |
|---|---|
| `continuous` | 长期输入 ≤ 可保证服务；再查突发与停顿 |
| `finite_frame` | 逐级峰值积压 ≤ 容量；采集入口始终收得下；采集后在限时内排空 |
| `periodic_burst` | 按完整的采集—排空周期与最坏停顿验证 |

空闲阶段未用的服务额度不得累加。

旧包与审查包给出的对照数字见 `06_testing.md` 第 4 节，预算器要逐项复现。

## 11. 评价

- 所有指标在固定且随结果保存的评价区域与掩膜下计算，并报告有效像素比例。
- 误差分解用均方误差、偏差、方差和消融项之间的交互；不用 RMSE 相减表示占比。
- 借助真值的配准只作为上界单独报告。
- 同时对"无模糊真值"和"光学参考（经光斑与采样后的真值）"两种基准报告。
- 斜边法 MTF 分扫描向与送片向；标注工作密度、扫描速度。

### 11.1 专用指标命令合同

`zlscan metrics --targets targets.json` 在既有双参考共有效掩膜上增加专用评价。
靶标清单版本为 `zlscan-quality-targets/1`，`evaluations` 列表包含独立命名的
`wedge`、`mtf`、`noise`、`banding`、`geometry`、`step` 项。清单内数组路径相对于清单目录。
每项可提供布尔 `region` 数组，与全局 ROI、标志位、有限值及双参考有效掩膜取交集；
最终掩膜按 `target_<name>` 随 `mask.npz` 保存。清单及外部数组 SHA-256 随结果保存。

- wedge：在 OD 域报告偏差与标准差；附透射率域的均值/标准差信噪比（20log10），零噪声时
  返回 null 并声明 zero_noise。可用范围必须有显式偏差和标准差阈值；不凭非空样本宣称可用。
- mtf：由密度转透射率后计算 ESF/LSF，距离为声明的边沿法向距离；输出空间频率单位 cycles/m。
  必须声明方向、工作密度和扫描速度；缺乏连续支持时报告不可计算。
- noise：仅接受同尺寸、完全落在最终掩膜内的矩形均匀区；缺样矩形整块排除，不能填零。
  PSD 为 OD²·m²，频率轴 cycles/m；去各块均值，DC 为零；区域是否均匀由靶标声明约束。
- banding：行均值来自当前图像的最终掩膜；逐面相位与边沿位置是评价输入，失锁相位保持负值。
- geometry：观测点与目标点成对输入，每点用对应像素索引门控，行距只使用评价掩膜涉及的行。
- step：显式声明行、连续列区间、边沿列和采样周期；区间含无效像素时不插值，报告不可计算。

以上只属于评价侧，不导入标定或重建。缺少或不适用的指标不生成虚构的数值。

## 11.2 带噪对数链的输入响应与适用范围（P0 修正）

每个时间格内的光电子电荷 Q 除以 dt，是该格的平均电流；不能把任意数值格宽直接当作
真实对数输入节点的物理响应。没有固定输入响应时，Poisson–Gamma 电流直接进入对数会产生
随 dt 改变的均值偏差。对数后的低通不能消除这一问题。既有 noisy demo/nominal 仅保留为
固定网格的探索算例，**不能据此判断高密度测量能力、带宽内噪声或实机精度**。

显式给出 `detector.pole_hz` 时，提供默认关闭的一阶输入节点研究模型（对应 M05 的电注入阶跃）：
tau = 1/(2π fc)，dy/dt = (I_bin − y)/tau，其中 I_bin = Q/dt 在一格内保持常数；
先按 y[k] = exp(−dt/tau)y[k−1] + (1−exp(−dt/tau))I_bin[k] 推进，再进入对数。
这是对时间格内电荷分布的近似，不宣称恢复真实单电子脉冲或 PMT 渡越时间。
初始节点电流为 0，预热时间由实验明确给出；状态跨块、跨行、跨标定阶段连续，进入检查点。

对恒定初级电子率 λ、每电子平均电荷 q=eG、倍增因子 F，该研究响应在有限格宽下的稳态矩为：
E[y]=λq，Var[y]=F λ q² tanh(dt/(2tau))/dt；dt→0 时为 F λ q²/(2tau)。
这给出独立于源码递推的解析验证。整链固定光功率、fc 与 ADC 时钟，仅改变 os，
检查带噪稳态均值、方差/带内谱、低光阶跃和独立标定残差的统计收敛，不能要求随机波形跨网格逐码相同。

本机 PMT 和输入电路传递仍未知，硬件参数继续为空。研究响应参数必须显式提供并标 ASSUMED；
它通过统计验证也只说明该候选模型的数值一致性，不升级为实机准确度或唯一正确拓扑。

### 11.3 扫描轨迹与窗口

扫描轨迹 P0 修正：`scan.geometry` 使用未夹紧的 u=(tau−tau_a)/active_s 计算物理位置，
光学有效区 inside、激光门控、底片边界、数字保留和输出裁剪分别处理。片外透射率由 Scene 声明。
场外 f-theta/畸变仍是所选研究映射的外推，不能作为真实光程或孔径测量。
只有显式 `legacy_clamped_coordinates=True` 才复现旧 V5 的坐标夹紧错误，并在适用性中标注；
该开关默认关闭，也未作为包 A/B 转换器的默认。修正后模型版本为 `chain-0.3`。

固定 ADC 1 MHz、对数前假设响应 20 kHz、对数后 30/50 kHz、白场初级电子率 1e8/s；
仅改变 os=4/8/16/32，分别使用独立的阶跃、拟合及验证随机种子，跨网格也不复用噪声实现。
阶跃在 1e6/s 与 1e5/s 间循环，两方向均保留状态；按重复实验汇总瞬态窗口、平台与固定窗带内谱。
标定使用暗/白及 D=0/1/2/3/4 已知参考，验证用未参与拟合的 D=0.5/1.5/2.5/3.5。
先码→线性化→扣暗/归一化→合并→密度，独立报告无效原因/比例与仅有效区的残差，不能删掉无效点后
仅报一个好看的 RMSE。原始 ADC 文件分别保存，拟合代码只接收原始参考与已知参考密度。

同时做逐网格拟合和固定最细网格拟合，后者防止重新标定吸收数值偏差。研究协议单独绑定同一组
假设的物理/ADC 参数，数值 os 和随机 seed 分别记录；该研究绑定不适用于正常 run 的配置绑定，
不改写生产标定文件、不放宽 require_applicable。独立验证标签只进入评价器，不进入拟合或重建。

预先声明研究数值等价界限：电压均值 5 mV、固定窗带内功率比 1.25 倍、网格间密度偏差差值
0.02 OD、无效比例差值 2 个百分点。它们是诊断精度假设，不是实机合格阈值，也不要求独立标定残差为零。
用重复实验的差值置信区间完全落在等价带内作为等价证据，分实验族作 Bonferroni 控制；
区间不相交或证据不足分别报告，不能以“未检出差异”或区间重叠代替等价证明。
共用最细标定引入共享拟合误差，对固定标定的网格差值按同一标定重复配对；其他比较按独立重复计算。
物理响应实测、其他参数范围及真实密度能力仍须独立验证，不由本协议自动解锁。

均值及对数功率比采用重复均值的 t/Welch 区间（近似分布假设）；无效比例在重复实验层用
[0,1] 有界的 Hoeffding 保守区间，配对比例差为 [-1,1]，避免全零观测时误报零不确定性。
有限重复下无效比例的 2 个百分点等价通常无法证明，必须保留证据不足，不降低阈值以求通过。


### 11.5 匹配控制与拟合再现

对相同光度研究 fixture 固定 os=32、响应/ADC/曝光窗口，交叉比较 shot_noise 开/关及
真实暗电流为 0 / 假设白场均值的 1e-3。各案例参考/验证使用独立 seed；确定性案例一次，随机案例八次。
零暗时 AFE 的 max(I,I_floor) 是数值下限，不等于可在线性域扣掉的加性暗电流；
用 log(T+d) 拟合这类 max 截断数据可能在没有噪声时就产生参考残差。
对确定性控制显式声明 1 码参考再现容差（含 ADC 量化），不将其当作实测不确定度。
随机控制未取得适当参考不确定度，不沿用 1 码阈值判定其是否合格。

独立验证先作为未验收候选的诊断，再应用已声明参考容差；不删除失败标记后送重建。
失败工件保留诊断但重建拒绝，未评估工件也不因此变成已验收标定。
暗电流控制只用于识别拟合假设，不是提高硬件暗电流的建议；条件差异不作 RMSE 相减贡献占比，
也不能证明对数下限是所有随机残差的唯一来源。

## 示波器观测候选模型（S6-T02）

只变换调用者提供的测点电压波形，不读取物理内态或真值。输入在声明的时间结点间
作线性插值；探头衰减后串联一阶探头低通、可选一阶 AC 高通、示波器本体低通及
带宽限制低通；最后按导出是否已补偿探头倍率恢复显示比例。各响应都是显式研究
近似，不把标称 −3 dB 带宽等同于已测得一阶传递函数；不含探头负载。
每极点 k=2πfc，低通 dz/dt=k(u-z)，AC 高通输出 u-z。
未知响应为 null，拒绝运行；显式 0 带宽表示理想旁路/关闭该限制，不代表未知。
DC 时不使用 AC 拐点，AC 时必须明确正拐点。初态必须显式零或首输入稳态。
将串联状态合成线性系统 dz/dt=Az+Bu、v=Cz+Du，源每个线性区间
通过增广矩阵指数推进（包括重复极点），避免逐级重新线性插值引入额外近似。
采样孔径 0 为点采样，正值为以时刻为中心的矩形平均；每个孔径从左端状态局部
积分，避免大累计积分相减。仅已有输入历史内计算，孔径越界为 null+原因。
采样时刻来自导入时间列，显式 model_time=scope_time+offset；偏移与初态
不由残差自动拟合，不确定度未知保留 null。输出永远是模型估计，不是实测。
