# 阶段 4：标定、重建、指标、成像视图

估算 4.5–6 人周。做出"尺子"：只用可观测数据的标定与重建，以及一整套评价指标。之后每加一个物理机制，都能立刻量出它对图像的影响。

**进入条件**：阶段 3 门槛通过。

**开始前**：通读 `04_physics_spec.md` 第 9、11 节，`03_contracts.md` 第 6、8 节，`06_testing.md` 第 2、3 节。把任务细化进 PROGRESS.md。

本阶段的每一行代码都受真值隔离约束：`calib`、`recon` 只接受原始码流读取器、可观测事件流、标定文件、`instrument` 与 `hardware` 配置。

## 任务

### S4-T01 标定扫描与标定文件

- 在实验时间线里生成标定扫描：遮光、无片、密度阶梯、锐边、刻线或网格、斜线。
- 标定文件读写，三种来源状态，绑定信息与适用性检查（`03_contracts.md` 第 6 节）。

**验收**：`SIMULATED` 状态的文件由标定扫描的原始数据生成；`MODEL` 文件默认被重建拒绝；硬件、增益、时期不匹配的文件被拒绝。

S3-T01/S4-T01录制端补充（D080）：暂停/完成从实际交付码流与有效控制设置导出捕获v2；
无数据不造描述，未来时期省略，逻辑复位保留物理设置。快照可接现有标定集合重建，
但不能代替参考扫描或实机标定，见 `docs/reports/recording_capture.md`。

### S4-T02 辐射标定

| 项 | 输入 | 输出 |
|---|---|---|
| 暗 | 遮光扫描若干行 | 逐列（逐面）暗值、分布、漂移 |
| 白 | 无片扫描若干行 | 逐列逐面白值与不确定度 |
| 传递 | 密度阶梯，或电流–电压表（包 B 的拟合工具是起点） | 码值 → 相对光强的查找表，含适用范围与外推策略 |

可配置平均行数、参考片缺陷（灰尘、划痕）、标定与扫描之间的漂移。

**验收**：注入已知的对数斜率与截距误差，标定恢复值落在其报告的不确定度内；参考片有缺陷时结果稳健或给出告警。

### S4-T03 延迟标定

用同向的上升沿与下降沿、已知刻线、同步电注入估计固定延迟与响应参数，两者分开。不使用反向扫描（没有证据表明硬件支持）。

**验收**：注入已知延迟后恢复；估计值不读取正向模型的延迟参数（导入边界测试覆盖）；整体配准偏移与"可独立标定得到的补偿"分开报告。

### S4-T04 几何标定

- 扫描向：刻线或网格加实测时序 → 逐面映射与残差。
- 送片向：斜线、网格或独立位移基准 → 逐面偏移。对均匀场返回 `unidentifiable`。
- 逐面增益：均匀场加可恢复的镜面相位分组；镜面相位由行同步周期推断，允许失锁，失锁时不得用真值镜面号补回。

**验收**：注入已知逐面误差与畸变后恢复；标定可辨识性测试通过；丢一个行同步后镜面相位进入"失锁"而不是悄悄继续。

### S4-T05 重建

按 `04_physics_spec.md` 第 9 节的默认参考路径。以 `legacy/package_b/reconstruct_capture.py` 为起点，流式处理。

- 无效原因标志位全部实现；无效像素密度为 `NaN`。
- 二维不规则重采样：声明坐标来源、支持范围、权重、边界规则；缺口超出支持范围保持无效。
- 输出随带单位、像素间距、掩膜、有效覆盖比例、算法版本、标定标识。
- `zlscan calibrate`、`zlscan reconstruct`。

**验收**：无静默夹紧测试；"先线性化再合并"由测试固定（对数码直接平均与规定路径的结果不同，且规定路径对合成算例是无偏的）；隔离测试与物理敏感性测试成对通过；输入可以是仿真码流，也可以是包 B 的无头格式。

分段采集补充：同一行的续包按原样本计数放置，保留缺口；无法定位的原包保持未定位。跨时期须由同一标定显式覆盖全范围，像素谱系 v2 保存每段身份。不同工作点的逐时期标定集合现由 D077、捕获v2及谱系v3接入，见 `docs/reports/epoch_calibrations.md`。逐样本先线性化后沉积；缺时期绑定、无匹配或歧义拒绝，跨时期无新逐面锚点标未解析。该软件路径不关闭整阶段或实机门槛。

本模块按"将来直接用于上位机"的标准写：不依赖仿真专用的数据结构。

### S4-T06 评价指标

`metrics/` 与 `zlscan metrics`：

| 类别 | 指标 |
|---|---|
| 密度 | 各阶梯偏差、标准差、线性度、可用范围、高密度平台值 |
| 分辨率 | 斜边法 MTF，扫描向与送片向 |
| 噪声 | 均匀场噪声功率谱、信噪比随密度 |
| 条带 | 逐面周期分量、行间抖动造成的边缘粗糙度 |
| 几何 | 网格点位置误差、行距、斜扫残余 |
| 完整性 | 样本覆盖、缺行、溢出、限幅、无效像素比例 |
| 动态 | 明暗阶跃后的拖尾与恢复 |
| 误差分解 | 均方误差、偏差、方差、消融交互 |

所有指标在固定且随结果保存的评价区域与掩膜下计算；对"无模糊真值"与"光学参考"分别报告。

**验收**：斜边 MTF 在合成算例上与理论值（光斑、带宽、采样三者之积）吻合；噪声功率谱对白噪声输入是平的；每个指标有一个已知答案的算例。

### S4-T07 标准实验集与误差分解

- 一组固定实验：理想链路；逐项加入一个误差；全部误差。
- 对包 B 的参考算例做配对消融：在相同评价区域、掩膜、标定条件下，分离对齐误差与其他误差源；区分"真值辅助配准的上界"与"可独立标定得到的补偿"。

**验收**：报告给出均方误差分解与交互项；不出现"RMSE 相减得占比"的表述。

### S4-T08 `nominal` 预设的完整验收

用 `SIMULATED` 标定跑通 `nominal` 的端到端，报告它与旧预设的差异及原因。这是第一次看到"标定不等于真值时"的真实误差。

**验收**：差异说明写入 `docs/reports/nominal_vs_legacy.md`。

### S4-T09 成像视图

工作台增加：图像与质量掩膜视图、当前扫描行、像素反查（该像素对应的样本集合与重采样权重，由重建按需重算）、两次运行的并排对比。

**验收**：点一个像素能跳到相关样本与时间范围；研究真值不进入标定与重建（W06）；标定与配置不匹配时界面可见。
