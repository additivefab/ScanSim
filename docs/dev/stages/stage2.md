# 阶段 2：数字最小闭环与第一级工作台

估算 5–7 人周。不涉及任何光学与模拟物理。从 ADC 测试码出发，贯通：输出链路 → 接收 → 标签 → 缓冲 → 多级队列 → 原始文件 → 完整性检查 → 最简重建，并让第一级工作台能看到这一切。

**进入条件**：阶段 0、1 门槛通过。

**为什么先做这个**：首要用途是算法与 FPGA 验证。数字链不依赖未知的物理参数，而且它定下的码流格式和样本身份是后面所有阶段的地基。

## 任务

### S2-T01 ADC 测试码源

- `adc/patterns.py`：固定码、交替码、斜坡、伪随机序列、从文件读入的码序列。两个通道可用不同的码。
- 产出"转换样本"：码值 + `SampleId` + `sample_time`。

**验收**：各测试码与其定义一致；伪随机序列可由种子复现。

### S2-T02 ADC 输出链路（功能级）

- `adc_link/`：码制（偏移二进制、补码）、并行或交织输出、数据时钟捕获边沿、位映射、通道顺序、溢出标志对齐、流水线延迟（区分输出模式，含 12 与 12.5 拍的情形）、输出传播延迟单列。
- 产出引脚级事件序列，每个样本得到 `adc_output_time`。
- 配置来自 `hardware.adc_module` 的生效配置；`hardware_constrained` 模式下配置未读回则拒绝。

**验收**：正确配置下，接收端还原出与源相同的码序列；每个延迟只计一次（用一个脉冲样本核对四个时间戳的差）。

### S2-T03 数字采集参考模型

- `digital/`：全部用整数运算。行同步的同步器与量化、行内计数、数字保留窗口、标签对齐（与数据同延迟）、打包成 `ZLRAW` 数据块、溢出与错误标志。
- 行同步输入是一个与 ADC 时钟不相干的物理时刻序列（本阶段由简单的周期源加抖动给出）。
- **默认不做数值聚合**：原始码原样打包。若配置了板端合并，只允许已线性化的数据，且配置里必须给出冻结的查找表与数值格式；对数码直接平均的配置被拒绝。

**验收**：每行保留的样本数与窗口定义一致；标签与数据对齐（参考包 A、包 B 的对齐测试）；不同行的采样相位随行同步的相位而变；对数码直接平均的配置报错。

### S2-T04 传输与缓存

- `transport/`：可配置的队列图（ADC 接收缓冲 → PL 侧缓冲 → DMA 环 → DDR 缓冲 → 传输队列 → 主机接收 → 落盘）。实际没有的级可从配置中去掉。
- 离散事件仿真：每级有容量与服务曲线（恒定速率、带停顿的分布，或回放一份记录）。ADC 不可反压；后级可反压。
- 记录每级的占用、峰值、排队延迟、溢出次数、丢失的样本区间。
- 溢出后不静默覆盖：生成丢失记录，帧标为不完整。

**验收**：样本守恒（按源样本身份查覆盖与重复）；注入各级停顿、断链、主机写盘失败，丢失记录指明层级与样本范围；与阶段 1 预算器在相同到达与服务曲线下的峰值积压一致。

### S2-T05 完整性检查与最简重建

- `io/integrity.py`：读回原始文件，核对块序号、样本序号连续性、CRC、时期，输出完整性报告。
- `recon/minimal.py`：不做任何辐射或几何校正，只按样本身份把码值排成"行 × 行内样本"的二维数组，缺失处置无效标志位 5。
- 完成条件：最后一个需交付的源样本已写入或已明确缺失、相关队列排空、输出已提交，才标为完成。

**验收**：无故障时重建数组与源码序列一致；有丢失时对应位置为无效而不是被后面的数据顶上来；提前中止时输出"不完整"状态并可追溯。

### S2-T06 RTL 协同

- 把 `legacy/package_b/rtl/` 的两个模块移入 `cosim/rtl/`，按参考模型补齐：行同步同步器、有效窗口、行计数。保持可综合的写法。
- 用 cocotb 驱动（Icarus 或 Verilator），激励来自 S2-T01 至 S2-T03，逐拍比对 RTL 输出与参考模型。
- 外部仿真器不可用时，本任务状态记为"未执行"，不得用参考模型自测代替。

**验收**：标准激励下逐位一致；`cocotb` 作为可选依赖加入前在 DECISIONS.md 记一条。

### S2-T07 故障注入与可检测性

- 故障：错边沿、错位序、错通道、溢出标志未对齐、测试码未退出、缺行同步、多余行同步、复位中断、时钟频差、缓冲回绕、位翻转。
- 每项按 `06_testing.md` 第 6 节记录：位置、检查主体、所需激励或冗余、检查点、可观测标志、检测时延、盲区。
- 区分"测试台知道注入了什么"与"实机运行期能发现什么"。

**验收**：每项故障要么被运行期可观测的标志检出，要么被如实报告为"当前配置不可判别"并给出增强办法（例如两通道用不同测试码）。

### S2-T08 控制状态与时期

- `control/`：状态机（未配置 → 已配置 → 稳定中 → 标定中 → 就绪 → 扫描中 → 排空中 → 完成；故障、中止）。
- 命令的请求、生效、读回确认分开记录；样本在采样时刻绑定生效配置；配置变更后仍在流水线里的样本保留原时期。

**验收**：扫描中途改配置，变更前采的样本带旧时期，变更后的带新时期；任一状态下复位产生新时期或不完整标记。

### S2-T09 第一级工作台

- 扩展 `ui/viewer/`：数字逻辑波形（时钟、行同步、有效窗口、溢出）、码值波形、唯一的时间游标、样本跟踪（四个时间戳与所经队列）、各级队列占用、丢样轨道、证据与来源标签。
- 数据以 `08_workbench_spec.md` 第 11 节同样的结构内嵌。

**验收**：W01–W04、W08、W12、W13 通过；选中一个码字能定位到它的采样时刻；在一个注入了溢出的运行里，能从丢样轨道定位到层级与样本范围。

### S2-T10 `zlscan run`（数字模式）与 `zlscan cosim`

- `zlscan run --mode digital`：跑通 S2-T01 至 S2-T05，输出运行目录、`run.json`、第一级网页。
- 隔离测试的最初版本：重建进程在只含可观测数据的目录里运行。

**验收**：一条命令产出完整运行目录；隔离测试通过。
