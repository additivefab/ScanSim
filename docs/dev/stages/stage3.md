# 阶段 3：合并基线物理模型、回放、第二级工作台

估算 7–9 人周。把两套旧包的物理模型按取舍合并进新架构，接到阶段 2 的数字链上；同时建立检查点、重放、迹线，以及第二级工作台。

**进入条件**：阶段 2 门槛通过。

**开始前**：本阶段任务多。先通读 `04_physics_spec.md`、`02_architecture.md` 第 4–5 节、`03_contracts.md` 第 7、9–11 节。然后把下面每个任务细化为若干子任务写进 PROGRESS.md，再动手。

## A 组：引擎与状态

### S3-T01 引擎

- `engine/`：多速率调度、按行块流式推进、状态在块之间传递、同刻事件的固定排序规则。
- 随机数工厂：按（种子、物理源、时钟域、序号）取数的计数器型生成器；有色过程带状态。
- 检查点的写入与恢复，内容见 `03_contracts.md` 第 11 节。

**验收**：分块一致、检查点一致两组测试的骨架就位（先用一个玩具的一阶滤波器模块验证）；随机数与分块无关。

### S3-T02 四种窗口与实验时间线

- 光学窗口、底片掩膜、数字保留窗口、输出区域各自独立配置。
- `experiment/`：预热 → 暗 → 白 → 标定靶 → 样片 → 复核，同一条时间线上状态连续。

**验收**：片外照明改变前端状态，即使对应码字被数字窗口舍弃（构造片外强光进入高密度区的场景，比较有无片外照明时片内前几个像素的输出）。

## B 组：物理模块（各自先写 `ModuleSpec`）

每个模块提供 L0 与 L1 实现，按 `04_physics_spec.md` 对应小节，来源取舍见 `01_project_brief.md` 第 3 节。

| 任务 | 模块 | 要点 |
|---|---|---|
| S3-T03 | `truth/scene` | 靶标库带解析真值；外部密度图；条带式超采样；片外规则 |
| S3-T04 | `truth/source` | 功率、逐行波动、纹波；常亮或门控；参考光通道默认关闭 |
| S3-T05 | `truth/scan` + `truth/timing` | L0 理想映射；L1 畸变、逐面偏移与增益、随机行抖动；连续或步进送片；行同步物理时刻 |
| S3-T06 | `truth/psf` + `truth/collect` | 物理尺寸高斯光斑，对透射率卷积；常数杂散；集光效率表 |
| S3-T07 | `truth/detector` | 泊松加 Gamma；暗事件；限幅告警；可选的渡越延迟与带宽极点（标 `ASSUMED`） |
| S3-T08 | `truth/afe` | 对数或线性、极性；固定带宽与电流相关带宽；驱动映射；抗混叠预设；一阶环节用精确递推 |
| S3-T09 | `truth/adc` | 采样、抖动、量化、饱和标志；接到阶段 2 的输出链路 |

各模块的**验收**：对应小节列出的固定性质都有测试；直流不变；步长收敛；噪声统计。

本阶段只做旧包已有的机制。眩光、异步行同步的完整模型、PMT 下垂、对数状态方程、交流耦合、噪声谱、ADC 非理想属于阶段 5。

### S3-T10 预设与旧结果复现

- `legacy_a`、`legacy_b` 两个预设：把旧包的行为（包括按行重置、真参数重建、`MODEL` 标定、夹紧）作为显式开关实现出来，只在这两个预设里打开。
- `nominal` 预设：连续状态、片外直通、精确离散化。它不允许使用 `MODEL` 标定，而基于可观测数据的标定要到阶段 4 才有，所以本阶段 `nominal` 只验证到 ADC 码流为止；完整重建在阶段 4。
- 旧配置转换器：包 A 的扁平配置、包 B 的分组配置 → V5 配置。

**验收**：两个旧预设在容差内复现 `06_testing.md` 第 4 节的数值，每处差异有解释；报告里标出旧预设的已知限制。逐位一致做不到时，先分析原因（随机数消耗顺序是最可能的原因）并记录，容差由用户确认。

### S3-T11 `zlscan run`（物理模式）与性能场景

- 整幅流式运行；内存占用与幅面无关。
- 性能场景：含标定阶段、片外模拟、读写、双通道。记录内核基准与端到端两套数字。

**验收**：性能算例 4000×5000 与 7000×8600 跑通，耗时与内存峰值记入证据记录。达不到目标就如实记录。

## C 组：观测、迹线、回放

### S3-T12 信号注册与只读探针

`telemetry/`：各模块通过 `observables()` 声明信号；探针只读，不改变输入与随机数轨迹。

**验收**：观察无扰动测试——开关任意探针、改记录策略，码流与重建结果逐位不变。

### S3-T13 迹线与摘要

`trace/`：按 `03_contracts.md` 与方案 5.14 节的记录策略。高频模拟量默认不落盘；选定探针写多层摘要（最小、最大、首、末、计数）；事件索引。

**验收**：摘要保真测试——在粗视图分辨率下，注入的单细步脉冲、削顶、溢出仍可见。

### S3-T14 重放

`replay/` 与 `zlscan replay`：从目标时刻之前最近的检查点恢复，向前重放指定窗口，结果只读发布。

**验收**：重放一致测试；实测检查点大小与单窗口重放耗时，写入证据记录，并据此确认或调整"每行一个检查点"。

### S3-T15 因果

`causality/`：样本链路（四个时间戳、所经队列、数据块）；线性环节的依赖窗口与截断误差。像素反查留到阶段 4。

**验收**：对一个注入的光脉冲，依赖窗口覆盖它影响到的所有样本，窗口外的样本不受影响（在声明的截断误差内）。

## D 组：第二级工作台

### S3-T16 查询服务

`api/` 与 `zlscan serve`：`08_workbench_spec.md` 第 11 节的接口。**加入 `fastapi` 等依赖前先问用户**，并确认前端由谁做、用什么框架。

### S3-T17 第二级前端

二维光路与信号链、探针、同步波形、任意定位与缩放、重放状态、未记录与未计算的显示、研究视图与实机可观测视图的切换。

**验收**：`08_workbench_spec.md` 的 W01–W11。物理纵向切片可见：密度边缘 → 光功率 → PMT → 前端 → ADC，各视图来自同一条真实运行轨迹。
