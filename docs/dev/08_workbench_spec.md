# 08 可视化工作台规格

## 1. 定位

以统一仿真时间为核心的观察工具，联动显示光路、器件状态、模拟波形、数字事件、缓存传输和成像过程。

**根本约束：前端不生成任何与后端状态无关的物理动画。** 画面上的每个数值、每条曲线、每个移动的光点，都来自一次真实运行的记录或重放。

## 2. 三级交付

| 级别 | 形态 | 建于 | 边界 |
|---|---|---|---|
| 第一级 | 每次运行生成一个自包含离线网页：数据内嵌，原生 HTML、SVG、Canvas、JavaScript，无外部脚本、字体、网络请求 | 阶段 0 骨架，阶段 2 可用 | 只覆盖短片段或单行；不支持重放与分支 |
| 第二级 | 本地 Python 服务加浏览器前端，按窗口查询，支持重放与分支 | 阶段 3 | 前端框架届时再定，先问用户 |
| 第三级 | 三维空间视图、布局保存、桌面封装 | 阶段 7，可选 | 三维只渲染，不参与计算 |

第一级的生成器在 `ui/viewer/`，输入是运行目录，输出是一个 `.html`。包 B 的 `legacy/package_b/src/viewer.py` 是可参考的起点。

## 3. 布局

```text
┌──────────────────────────────────────────────────────────────┐
│ 实验 / 运行 / 时期 / 模型等级 / 配置模式 / 证据汇总 / 数据完整性│
├──────────┬───────────────────────────────┬───────────────────┤
│ 组件树   │ 光路与器件视图（二维）        │ 当前组件探针      │
│ 光学链   │ 激光 → 扫描 → 底片 → 集光     │ 数值、单位、来源  │
│ 模拟链   │                   ↓ PMT       │ 状态、适用范围    │
│ 数字链   │ 前端 → ADC → FPGA → 缓冲      ├───────────────────┤
│ 图像     ├───────────────────────────────┤ 样本追踪          │
│ 事件     │ 模拟波形 / 数字逻辑波形       │ 采样 → 输出 → 接收│
│          │                               │ → 缓存 → 主机→像素│
├──────────┴───────────────────────────────┴───────────────────┤
│ 时间轴：实验总览 → 帧 → 行 → 像素 → ADC 拍 → 纳秒            │
│ 播放 / 暂停 / 单步 / 跳转 / 缩放 / 事件定位 / A-B 游标         │
└──────────────────────────────────────────────────────────────┘
```

窄屏下各区域纵向堆叠，页面不出现横向滚动。

## 4. 唯一的时间游标

- 全页只有一个游标，状态是（运行、分支、时期、时刻）。所有视图订阅它。
- 浏览器的刷新时钟只决定何时重画，不推进物理时间。播放时，每帧按"每现实秒推进多少仿真时间"计算新的游标位置，再向数据取值。
- 时刻用整数刻度的字符串传递；绘图时换算成相对视窗原点的偏移。

## 5. 三种显示语义

界面上是三个有名字的模式，不混在一起。

| 模式 | 回答的问题 | 做法 |
|---|---|---|
| 同时刻观察 | 此刻整机各处是什么状态？ | 每个组件显示自己在该时刻的值；各处的时间错位如实保留 |
| 样本跟踪 | 这个码字怎么走到主机的？ | 选中一个样本，显示它的四个时间戳、经过的队列、所在数据块、落到的像素；高亮波形上的对应位置 |
| 因果回溯 | 这个像素或码字受哪段输入影响？ | 线性环节显示依赖窗口与截断误差；非线性环节只显示已定义的依赖范围 |

## 6. 时间轴

- 三层：总览（预热、暗、白、标定、样片、复核、排空）；帧与行；细层（像素覆盖、ADC 采样与输出、接收拍）。
- 操作：播放与暂停；按 1 纳秒或自定步长前后移动；上一个或下一个 ADC 采样、行、异常事件；输入时间或样本序号直接跳转；缩放到选区；A/B 游标与时间差。
- 播放速度显示为"每秒推进 100 ns"这样的绝对量。
- 暂停时冻结一切与仿真过程有关的画面。

## 7. 四种时间精度

每条信号旁边显示：

| 项 | 来源 |
|---|---|
| 时间表示分辨率 | 刻度单位 |
| 游标定位分辨率 | 当前步长 |
| 模型分辨率 | 该信号的原始步长或采样周期 |
| 测量能力 | 实测数据的采样间隔与对齐不确定度；仿真数据为空 |

## 8. 不得误导的规则

| 情形 | 必须怎么显示 |
|---|---|
| 查询状态为 `not_recorded` | 空白，并标"未记录" |
| `not_computed` | 标"未计算" |
| `summary_only` | 画最小值到最大值的包络，并标"摘要" |
| `interpolated` | 标"插值"；原始点另用标记画出 |
| 放大到比原始采样更细 | 显示实际采样点与保持阶梯，不画平滑曲线 |
| 逻辑信号 | 跳变与持续区间，不做平滑 |
| 未建模的环节（如 PMT 快响应） | 标"未建模"或"假设"，不画细节动画 |
| 参数为假设 | 探针里标出证据等级 |
| 研究视图中的真值 | 标"仿真真值，实机不可见" |
| 非同次采集的实测数据 | 不画成逐点同步；显示对齐不确定度 |
| 各种"通过"状态 | 分开显示，不合并成一个总灯 |

状态除颜色外还要有文字或图形。

## 9. 两种视图

- **研究调试视图**：可看真值与内部状态。数据来自只读探针。
- **实机可观测视图**：只显示 `visibility=OBSERVABLE` 的内容，等同于实机上能看到的东西。

从研究视图导出的截图、数据、报告带"含仿真真值"标签。界面状态保存再导入，不得把真值字段变成标定输入。

## 10. 各组件的探针内容

| 组件 | 显示 | 点击后 |
|---|---|---|
| 激光与光路 | 光源、路径、扫描方向、光斑位置 | 功率、波长、路径来源、传播模型 |
| 扫描光学 | 转镜姿态、当前面、扫描窗口 | 角度定义、映射、面相位的来源（测得或推断） |
| 底片 | 密度或透射率、片夹、片外区、已扫位置 | 被照区域、积分权重、四种窗口状态 |
| PMT | 入射功率、光电子统计、电流 | 量子效率、增益、噪声、快响应参数及来源 |
| 模拟链 | 各测点的电压 | 该测点的定义；对数板输出、主放输出、模块输入、芯片差分输入分开 |
| ADC | 采样点、保持值、量化码 | 当前采样序号与当前输出序号 |
| FPGA | 接收拍、位映射、行同步、有效信号 | 时钟域、标签、错误标志 |
| 数据通路 | 各级队列占用 | 容量、服务、丢样区间、守恒账本 |
| 成像 | 已形成的图像、掩膜、当前行 | 该像素对应的样本集合与权重 |

光路是功能示意。图上的距离不代表真实光程，画出的光线不是光线追迹；界面上写明这一点。

## 11. 查询接口（第二级）

建议规格，第二级才实现。第一级把同样结构的数据直接内嵌在网页里，这样两级共用同一套前端取数逻辑。

```text
GET  /runs/{id}/manifest
GET  /runs/{id}/signals
GET  /runs/{id}/state?tick=…&components=…
GET  /runs/{id}/traces?signals=…&start=…&end=…&pixel_width=…
GET  /runs/{id}/events?start=…&end=…&kinds=…
GET  /runs/{id}/samples/{sample_id}/lineage
GET  /runs/{id}/images/{image_id}/tiles/…
POST /runs/{id}/replay-window
POST /runs/{id}/branches
WS   /runs/{id}/updates
```

- 每个响应带查询状态（`03_contracts.md` 第 10 节）和所取的摘要层级。
- 连续拖动时旧查询可取消；前端按请求序号丢弃迟到的结果。
- 仿真计算与服务的事件循环分开进程。
- 服务只读运行数据；重放结果单独发布，不写回原运行。

### 11.1 波形查询载荷合同（2026-11-12 增补）

`traces` 的 pixel_width 为 1..4096 整数。ADC 窗口不超过 2×pixel_width 时返回原始点，
否则返回至多 pixel_width 个 min/max/first/last/count 桶，不能用均值取代异常。
模拟摘要如层级不足以满足载荷上限，在已记录摘要上继续合并并明确报告实际支撑范围；
放大超过记录精度时仍为 not_recorded，不从摘要猜测原始点。
所有路径都限制窗口到真实运行/记录范围，禁止负数组切片，完全无数据时明确空态。
摘要的边缘桶可能超出所请求窗口，须携带实际支撑范围和说明，不能隐称精确窗口数据。

查询坐标仍为模型细步；返回 first_step 与 block_steps 供前端定位。ADC 另外携带源样本原点、
有理采样周期和首末真实采样时间，时间与源样本序号以十进制字符串传输。
原始 ADC 绘制点和保持阶梯；摘要绘制极值包络。摘要只用于显示，不进入标定、重建或评价。

### 11.2 成像运行的只读服务合同

`zlscan serve --images registry.json` 注册已完成的观测重建结果。注册清单含 `runs` 列表，
每项具有唯一 `id`、`reconstruction` 目录和可选 `raw` 路径，路径相对清单位置；
可选 `expected_calibration_id` 声明当前期望标定，`expected_binding` 声明当前完整采集绑定。不得将图像附着到无关的 demo 轨迹。
重建输出包含 `lineage.json`：实际使用的扫描向坐标表、逐行 y、已交付块的源样本身份、
时钟与文件偏移。坐标来自已声明坐标或可观测标定，不能读取仿真真值。

新增接口：

```text
GET /runs/{id}/images
GET /runs/{id}/images/density/manifest
GET /runs/{id}/images/density/tiles/0/{tile_x}/{tile_y}
GET /runs/{id}/images/density/pixels/{row}/{column}/lineage
```

瓦片为最多 256×256 的原分辨率密度、标志位与支持权重，非有限值按 JSON null。
谱系根据重建保存的实际坐标重算双线性权重，包含跨行贡献和逐面映射。
无效像素只报告几何支持候选，归一化权重为 null；缺失行不制造样本编号。
绑定不符、来源文件变更或缺少谱系均明确报告，不能画成已验证的图像。
注册的期望标定或采集绑定失配时显示 CALIBRATION_MISMATCH，并隐藏密度值。
匹配的原始码查询同样遵守显示预算，保留缺口为 null；摘要另带 recorded_counts 与 missing_count，
count 包括时间轴中的缺失样本位置，不能将间隙连成一段保持值。

成像运行的游标单位为相对源样本序号，原点及绝对时间以十进制字符串传递；
样本时间由采集时钟整数运算计算。点击像素选中其第一个实际贡献样本，所有视图共用此游标。
两次运行可按同一像素坐标并排查看，各自显示真实采样时间；这不声明两次采集逐点同步。

### 11.3 冻结 recording 目录

`serve --run` 也识别 recording 定义/统一根；每物理通道注册独立运行。
仪器 ADC 取冻结交付前缀，保留缺口/时期/混合桶；样本详情只提取原捕获白名单向量。
研究 trace/state/replay 按真实历史控制只读重放，最多一百万细步，缺历史不造起点。
原链路方程推导与模拟传输诊断单列研究数据，主机到达未知。页面标冻结只读；
超过浏览器安全整数的整体轴禁用。详见 `docs/reports/recording_workbench.md`；
实时尾随、持久探针游标与完整视觉验收仍未完成。

## 12. 分支

视角、配色、曲线显隐不产生新运行。改变任何物理或硬件配置都创建新分支，或记录为带生效时刻的控制事件。历史结果不被覆写。

## 13. 验收

| 编号 | 测试 | 通过标准 |
|---|---|---|
| W01 | 跨视图同步 | 所有视图显示同一运行、时期、时刻的数据 |
| W02 | 暂停与回看 | 暂停后画面不漂移；反复定位返回相同记录 |
| W03 | ADC 时间语义 | 四个时刻各自正确；相差一个流水线时不认错样本 |
| W04 | 记录不足 | 显示保持或插值标记；缺数据不伪造 |
| W05 | 观察无扰动 | 开关探针、切换视图、拖动，不改变码流与重建结果 |
| W06 | 研究探针隔离 | 导出内容带标签；不能经界面进入标定或重建 |
| W07 | 窗口区别 | 片外照明影响前端状态，即使对应码字被数字窗口舍弃 |
| W08 | 数字故障 | 溢出、缺包、错位序能追到层级与样本范围 |
| W09 | 摘要保真 | 粗视图仍能看到短脉冲、极值、故障 |
| W10 | 回放与分支 | 同轨迹可复现；换步长或机制标为新分支 |
| W11 | 查询竞争 | 快速拖动后，迟到的结果不把画面跳回旧时间 |
| W12 | 离线 | 第一级网页断网可用，无外部请求 |
| W13 | 布局 | 宽屏与窄屏下无横向溢出 |

W01–W04、W08、W12、W13 在第一级就要满足。界面测试用无头浏览器（本机可用的方式在阶段 2 确定并记入 DECISIONS.md）；无法自动化的项写成人工核对清单，并在 PROGRESS.md 记录是否执行。

交互指标（已缓存时间窗定位在 150 毫秒内、每秒 30 帧）是目标，阶段 3 实测后再定是否作为验收。
