# 01 项目简介

读完本文件，你应该知道：这台设备怎么工作、手头有哪些资料、哪些已知哪些未知。

## 1. 设备与信号链

一台透射式激光底片扫描仪：激光逐点照明已显影的底片，光电倍增管（PMT）接收透过的光，时间信号按扫描位置拼成二维密度图。单波长、单探测通道、灰度。

```text
激光 → 准直整形 → 旋转多面镜 → 扫描聚焦镜组 → 底片 → 集光（板状导光件）→ PMT
     → 对数放大板（一级）→ 二级主放 → ADC 模块（AD9268，双通道 16 位）
     → FPGA 开发板（Zynq-7020）→ DDR / 网口 → 上位机 → 标定 → 重建 → 密度图
```

旁路：转镜驱动与行同步（SOS）、送片电机与可能的编码器、PMT 高压模块、载板上的 DAC 控制（去向未知）。

关键物理事实：

- 光学密度 `D = -log10(T)`，T 为透射率。D=3 时只有千分之一的光透过。
- PMT 不是相机，任一时刻只有一个电信号；像素坐标来自"第几行、行内第几个采样"。
- 同一时刻整机是并行的：光斑在位置 A，模拟输出还混着位置 B 的响应，ADC 总线上是更早的位置 C 的码字。

## 3. 两套旧包的差别（决定了合并基线怎么取）

| 环节 | 取谁 | 原因 |
|---|---|---|
| 时间轴与滤波器状态 | 包 B | 整行连续、状态跨行保持 |
| 片外区域 | 包 B | 透明直通 |
| 底片超采样、物理尺寸光斑 | 包 A | 在 4 倍超采样网格上对透射率卷积 |
| 逐面增益与偏移、杂散光、电流相关带宽 | 包 A | 包 B 没有 |
| 对数 / 线性前端切换、前端到 ADC 的增益偏置映射 | 包 B | 包 A 没有 |
| 一阶低通离散化 | 包 A | 分段线性输入的精确递推，收敛好一个量级以上 |
| 标定文件、独立重建命令、对数拟合 | 包 B | |
| 无效掩膜、对照实验 | 包 A | |
| RTL 起点 | 包 B | 两模块，含行末、帧首、丢样计数 |

两套包共有的缺陷，也是本工程要解决的：

- 重建直接用正向模型的真参数，标定无噪声。
- 行同步理想，每行从同一采样相位开始。
- 没有随信号变化的眩光。
- 指标只有 RMSE。
- 整帧数组驻留内存。
- 把非正透射率夹成极小值再输出。

## 4. 已知与未知

**已知（有资料支持）**

- 开发板：Smart ZYNQ SP2 V1.3B，XC7Z020，512 MiB DDR 接在 PS 侧，PL 有 50 MHz 晶振。
- J5 属 BANK35（3.3 V），J6 属 BANK33（VADJ，默认 3.3 V）；J5 新旧版引脚排列不同。
- 千兆网口 PHY（RTL8211E）接在 PL；USB 数据口为 USB 2.0。
- ADC 模块丝印：ADC_AD9268_V4.2，双通道，16 位，125 Msps。
- 载板丝印：二级增益主放、DAC 控制、电机控制、传感器 1。

**未知（不得填入默认值）**

- 激光波长与功率；转镜面数与转速；行频；镜组焦距与光斑。
- PMT 与高压模块型号；对数板与载板的电路；二级主放增益与偏置。
- ADC 实际采样率、时钟源、输出模式、接口电平、是否直流耦合、寄存器配置。
- ADC 模块到开发板的接线；DAC 控制的去向；第二个 ADC 通道的用途。
- 行同步信号的真实来源；是否有编码器和每转参考。
- 产品规格：底片幅面、像素间距、密度范围与精度、扫描时间。

旧包里出现的数值（635 nm、1 mW、6 面、10000 rpm、20 或 50 MSPS、增益 1000 等）全部是教学假设，只能作为 `research` 模式的示例预设。

## 5. 四种用途

| 代号 | 用途 | 说明 |
|---|---|---|
| U0 | 可行性 | 预算器：几何自洽、光子、电信号、数据通路，不运行仿真 |
| U2 | 算法与 FPGA 验证 | 数字参考模型、RTL 协同、可观测性合同 |
| U1 | 设计权衡 | 行为模型、参数扫描、像质指标 |
| U3 | 实测解释 | 实测导入、辨识、独立验证 |
| U4 | 时序观察 | 工作台；随每个阶段交付，不单独排序 |

优先级 U0 → U2 → U1 → U3。

## 6. 术语

| 术语 | 含义 |
|---|---|
| 真值世界 | 正向物理模型及其内部状态，重建不可见 |
| 仪器认知 | 标定与重建一侧，只能用实机上读得到的数据 |
| 细步 | 模拟链的内部时间步，比 ADC 采样周期细 |
| 时期（epoch） | 配置或复位之间的一段；配置一变就换时期 |
| 四种窗口 | 光学窗口、底片掩膜、数字保留窗口、输出区域，互相独立 |
| 检查点 | 能完整恢复仿真状态的快照 |
| 研究模式 / 硬件约束模式 | `research` 允许假设与外推；`hardware_constrained` 缺资料即拒绝 |
| 三级工作台 | 第一级离线网页；第二级本地服务加前端；第三级三维与封装 |
